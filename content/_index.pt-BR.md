## [LightCMS](https://lightcms.me) é um sistema de gerenciamento de conteúdo baseado no Git para sites estáticos

**Seus posts permanecem no seu repositório como arquivos Markdown.** Todos os rascunhos e posts vivem como Markdown com o assunto principal. O Git mantém o histórico de versões, para que você possa rever alterações, reverter e continuar a trabalhar em qualquer editor que quiser.

1. **Um editor visual.** [LightCMS](https://lightcms.me) usa o editor [TipTap](https://tiptap.dev) para escrever e formatar no navegador.
2. **Um OI copilot.** Use-o para revisar e melhorar rascunhos.
3. **ditado por voz.** Fale e deixe sussurro ou [Wit.ai](http://Wit.ai) transformar suas palavras em texto.
4. **Temas claros e escuros.** Escolha o tema que mais lhe convier.
5. **Boletins informativos sem um serviço de terceiros.** [Newsy](https://github.com/light-cms/newsy) transforma cada postagem recém publicada em um anúncio no GitHub, para que os leitores possam se inscrever lá.

---

## Como funciona

1. **Entre** com a sua conta no GitHub.
2. **Escolha um repositório.** Instale o aplicativo LightCMS no repositório que mantém o seu site. Funciona com geradores de site estáticos que usam a questão frontal em arquivos Markdown.
3. **Escreva.** O editor lida com a formatação e envia imagens conforme você as adiciona.
4. **Publish.** [LightCMS](https://lightcms.me) commits a alteração no seu repositório. Suas compilações de pipeline CI/CD e implantam o site no host que você escolher, como o GitHub Pages, Páginas Cloudflare, Netlify, Vercel, [Surge.sh](https://surge.sh), ou qualquer armazenamento de objetos compatível com S3.
