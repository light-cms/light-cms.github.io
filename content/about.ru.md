Статические генераторы сайтов легко подобны после их установки. Написание для них может быть другой историей. Быстрый пост не должен требовать открытия редактора кода, исправления передней части дела и толкания Git коммита.

Мы создали [LightCMS](https://www.lightcms.me/), чтобы вы могли писать в браузере и сохранить каждый пост как Markdown файл в вашем собственном репозитории GitHub. Этот сайт является нашим ноутбуком, так как мы строим LightCMS. Мы пишем о том, что работает, где публикация из Git становится неудобной и что требуется для поддержания различных статических инструментов сайта.
