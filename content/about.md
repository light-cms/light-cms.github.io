The LightCMS Journal publishes guides and design notes about Git-backed publishing, static site generators, and [LightCMS](https://www.lightcms.me/). It is written for people building or maintaining static sites who want content workflows that keep Markdown and version history in Git.

## What this site covers

The posts on this site focus on practical publishing decisions: how Git-based CMS workflows compare with database-backed systems, how static site generators fit different projects, and how deployment and content operations work together.

If you are new to the project, start with these pages:

- [What LightCMS is](/blog/what-is-lightcms/) explains how the editor connects to a repository.
- [Why we built it](/blog/why-this/) describes the trade-offs behind the project.
