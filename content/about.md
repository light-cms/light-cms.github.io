Static site generators are great once they're set up, but actually writing on them can be a chore. Opening a code editor, fixing front matter syntax, and pushing Git commits shouldn't get in the way of publishing a short post.

We built [LightCMS](https://www.lightcms.me/) so you can write in a browser editor while keeping every post as plain Markdown in your own GitHub repository. This site is our notebook from building it. We write about what works, where Git-backed publishing breaks down, and how different static site tools compare when you actually have to maintain them.

This site runs on Zola, and we manage all of its posts with LightCMS.
