Static site generators are easy to like once they are set up. Writing for them can be a different story. A quick post should not require opening a code editor, fixing front matter, and pushing a Git commit.

We built [LightCMS](https://www.lightcms.me/) so you can write in a browser and keep each post as a Markdown file in your own GitHub repository. This site is our notebook as we build LightCMS. We write about what works, where publishing from Git gets awkward, and what it takes to maintain different static site tools.
