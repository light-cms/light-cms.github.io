# About

This is a basic displayable Zola starter with a built-in minimal theme (no external theme). It includes:

- Home page (`templates/index.html` + `content/_index.md`)
- Blog section (`content/blog/`)
- Base, section, and page templates in `templates/`
- Plain CSS in `static/css/style.css`

Run `zola serve` to preview, `zola build` to build to `public/`.
