[LightCMS](https://www.lightcms.me) — система управления контентом для статических генераторов сайтов. Он сохраняет ваш контент как Markdown в Git, где вы можете редактировать его в браузере, просмотреть изменения и опубликовать в уже используемом конвейере CI/CD.

## Что вы можете сделать с LightCMS

| Способность           | Как это работает                                                                                                              |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| Визуальное изменение  | Напишите и редактируйте Markdown в вашем браузере.                                                                            |
| Публикация Git        | Сохраняйте изменения как коммиты в вашем репозиторие, а не в отдельной базе данных.                                           |
| Обзор                 | Использовать ветки, Pull Request и историю Git для просмотра изменений.                                                       |
| Обновления для чтения | Отправлять обновления через GitHub рабочих процессов с такими инструментами, как [Newsy](https://github.com/light-cms/newsy). |

## Как работает публикация

1. Войти через GitHub.
2. Выберите репозиторий с содержимым вашего сайта.
3. Напишите или отредактируйте пост в браузере, в том числе и в любом переднем ряду вашего сайта.
4. Опубликовать изменения на Git.
5. Пусть ваш существующий трубопровод, такой как GitHub Actions, Cloudflare Pages, Vercel, Netlify, строить и развертывать сайт.
