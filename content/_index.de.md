## [LightCMS](https://lightcms.me) ist ein Git-basiertes Content Management System für statische Seiten

**Deine Beiträge bleiben als Markdown Dateien in deinem Projektarchiv.** Jeder Entwurf und jeder Beitrag lebt als Markdown mit Frontmaske. Git speichert die Versionsübersicht, so dass Sie Änderungen überprüfen und zurücksetzen können und in jedem Editor, den Sie mögen, weiterarbeiten können.

1. **Ein visueller Editor.** [LightCMS](https://lightcms.me) verwendet den [TipTap](https://tiptap.dev) Editor zum Schreiben und Formatieren im Browser.
2. **Ein KI-Copilot.** Benutze es um Entwürfe zu überarbeiten und zu verbessern.
3. **Sprachdiktation.** Sprechen und lassen Sie Flüstern oder [Wit.ai](http://Wit.ai) Ihre Worte in Text verwandeln.
4. **Helle und dunkle Themes.** Wähle das Thema, das dir passt.
5. **Newsletter ohne Drittanbieterdienst.** [Newsy](https://github.com/light-cms/newsy) verwandelt jeden neu veröffentlichten Beitrag in eine Ankündigung auf GitHub, so dass die Leser dort abonnieren können.

---

## So funktioniert es

1. **Anmelden** mit deinem GitHub-Konto.
2. **Wählen Sie ein Repository aus.** Installieren Sie die LightCMS App auf dem Repo, der Ihre Seite enthält. Es funktioniert mit statischen Seitengeneratoren, die Frontmatter in Markdown Dateien verwenden.
3. **Schreiben.** Der Editor bearbeitet die Formatierung und lädt die Bilder beim Hinzufügen hoch.
4. **Veröffentlichen.** [LightCMS](https://lightcms.me) überträgt die Änderung in deinem Projektarchiv. Ihre CI/CD-Pipeline baut und verteilt die Seite auf den gewünschten Host, wie z. B. GitHub Pages, Cloudflare Seiten, Netlify, Vercel, [Surge.sh](https://surge.sh) oder S3-kompatible Objektspeicher.
