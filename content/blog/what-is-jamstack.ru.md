Jamstack - это веб-архитектура, сочетающая в себе готовую разметку, API и JavaScript. Вместо того чтобы отображать каждую страницу с сервера приложений по каждому запросу, Jamstack сайт обслуживает предварительно собранные файлы с CDN и использует API или клиентский JavaScript для динамических функций.

## Три компонента Jamstack| Компонент | Роль | Пример |

\| :--- | :--- | :--- | | Разметка | Создан HTML при сборке | генератор статических сайтов | | API | Динамические возможности вне рендеринга страницы | Формы, поиск, платежи, auth | JavaScript | JavaScript | Обработка на стороне клиента | Поисковый интерфейс, комментарии, персонализация |

Архитектура не такая как "нет JavaScript" или "нет динамического поведения". Это означает, что по умолчанию путь доставки достроен и кэширован, а динамическое поведение добавляется сознательно.

## Почему команды используют Jamstack

Jamstack сайты могут быть быстрыми, кэшируемыми и функционально простыми для содержательных проектов. Они также хорошо подходят с основанными на Git рабочими потоками: изменение содержания вызывает сборки, а развертывание производит неизменяемые ресурсы.

На краях сложность торговых переговоров. Аутентификация, предпросмотр, персонализация и данные в режиме реального времени часто требуют сторонних услуг, безсерверных функций или гибридной визуализации.

## Джамстек в современной практике

Современная структура размывает линию между статическими и динамическими. Astro, Next.js, SvelteKit и другие могут сделать предварительный просмотр некоторых маршрутов и сделать другие динамическими. Это делает "Jamstack" менее строгим правилом и более полезным по умолчанию: создайте то, что вы можете, использовать динамические сервисы там, где это необходимо.
