Hugo и Astro Starlight могут создавать быстро статические сайты документации из Markdown контента. Hugo - это генератор статического сайта общего назначения, который вы адаптируете для документации с темами и шаблонами. Starlight - это шаблон документации Astro с общими функциями доска, настроенными с самого начала.

## Сравнение функций

| Функция                        | Hugo + docs тема                                           | Звёздный свет Astro                           |
| :----------------------------- | :--------------------------------------------------------- | :-------------------------------------------- |
| Основная модель                | Общая цель SSG с темами docs                               | Шаблон Astro, ориентированный на документацию |
| Sidebar/navigation             | Тема - или зависимость от шаблона                          | Встроенные шаблоны                            |
| Искать                         | Обычно добавлено через тему или внешний инструмент         | Интеграция Pagefind обычно включает в себя    |
| Поддержка MDX/компонента       | Шаблоны шорткодов/пользовательских шаблонов; MDX не родной | Поддерживаются MDX и связанные с ним острова  |
| Проверка содержимого           | Пользовательская проверка                                  | Проверка коллекции контента/схемы Astro       |
| Построить цепочку инструментов | В бинарный файл                                            | Node.js/Astro toolchain                       |

## Где Hugo вписывается в проекты документации

Hugo - это сильный выбор, когда скорость сборки, однодвоичная цепочка инструментов или существующая настройка Hugo. Большие наборы документации могут извлечь пользу из быстрой сборки, а команды, уже знакомые с шаблонами Go, могут настраивать макеты без добавления фреймворка JavaScript.

Торговля заключается в том, что многие функции документации зависят от качества темы или пользовательской реализации. Поиск, варианты версий и поведение навигации могут варьироваться в зависимости от тем.

## Где Звездная документация соответствует проектам

Starlight является сильным выбором, когда вы хотите документацию конвенций, доступных ранее: боковая структура, поиск, i18n леса, и доступные компоненты. Ее основа Astro также облегчает встраивание интерактивных компонентов на страницах MDX.

Сложность трейд-офф - сложность инструментальной цепочки. Вы берете на зависимости Node.js и на экосистему Astr, которая может быть более чем простым документооборотом потребностей сайта.

## Выбор между Уго и Звёздным Светом

Выбирайте Hugo, когда вам нужна минимальная цепочка инструментов, уже работают с сайтами Hugo, или ожидайте очень большие сборки, где скорость Хаго является приоритетом. Выберите Starlight, когда вы запускаете новый сайт документации и хотите использовать стандартные для работы с документацией с расширениями компонентов.

Оба подхода работают с Markdown в Git. Основанный на Git CMS типа [LightCMS](/getting-started/) может соответствовать любому рабочему процессу, если он коммитирует Markdown файлы в репозиторий.
