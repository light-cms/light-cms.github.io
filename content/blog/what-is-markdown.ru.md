Markdown - это формат разметки обычного текста для написания структурированных документов простыми символами. Он обычно используется для документации, файлов README, заметок, и статический контент сайта, потому что исходный код остается читаемым как текст и может быть преобразован в HTML.

## Основной синтаксис Markdown

````md
# Заголовок 1

## Заголовок 2

абзац жирным и _italic_ текстом.

- Стрелочный предмет
- Другая пуля предмета

1. Пронумерованный предмет
2. Другой нумерованный элемент

[Текст ссылки](https://example.com)
![Alt text](/images/photo.jpg)

`inline code`

```js
console.log("Привет, web");
```
````

Различные параметры Markdown добавляют такие функции, как таблицы, списки задач, сноски и атрибуты огороженного кода. Общие вкусы включают CommonMark и GitHub Flavored Markdown.

## Почему Markdown хорошо работает для статических сайтов

| Свойства          | Практическая выгода                                          | Сделка                                                |
| :---------------- | :----------------------------------------------------------- | :---------------------------------------------------- |
| Обычный текст     | Легко хранить, распространять и версию в Git                 | Ограниченный порядок макета без расширений            |
| Читаемый источник | Авторы могут редактировать без собственного редактора        | Сложные документы могут потребовать MDX или шорткодов |
| Конвертация HTML  | Статические генераторы сайтов показывают их на веб-страницах | Выход зависит от генерации и темы                     |
| Портабельность    | Файлы могут перемещаться между инструментами и платформами   | Различия вкуса могут повлиять на рендеринг            |

## Markdown и передняя часть

Статические генераторы сайтов часто сопрягают Markdown с передним вопросом, блок метаданных в верхней части файла.

```md
---
title: "My First Post"
date: 2026-10-14T10:00:00Z
tags:
  - blogging
---

The article body starts here.
```

Контент магазина для магазинов. Вместе они образуют портативный формат контента для основанных на Git процессов публикации. Подробнее см. [Что такое Фронт в Markdown?](/blog/what-is-front-matter/) и [Что такое CMS?](/blog/Git based-cms-explained/).
