Страницы с облаком и страницы с GitHub могут бесплатно размещать статический сайт, но они соответствуют различным рабочим потокам. GitHub Страницы удобны, когда ваш сайт уже живет в GitHub и трафик скромный. Облачные страницы лучше подходят для предварительного просмотра, более широкой доставки или меньшего количества пропускной способности.

## Сравнение функций

| Область                                | GitHub Pages                                     | Страницы с облаком                                                            |
| :------------------------------------- | :----------------------------------------------- | :---------------------------------------------------------------------------- |
| Основное место                         | Документация проекта, простые персональные сайты | Статические сайты, блоги, маркетинговые сайты                                 |
| Ограничения ширины/использования       | Применяются лимиты использования                 | Бесплатный уровень включает в себя неограниченную пропускную способность      |
| Предварительный просмотр развертывания | Не построено как стандартный PR превью           | Автоматический предварительный просмотр URL для непроизводственных ветвей/PRs |
| Край/сеть                              | Доставка с поддержкой CDN                        | Облачная глобальная кромка                                                    |
| Функции сервера                        | Только статика                                   | Доступна интеграция функций и рабочих страниц                                 |

## Трафик и риск трафика

GitHub Страницы публикует рекомендации по использованию, включая пропускную способность, размер сайта и ограничения частоты сборки. Для небольшого сайта с документацией эти ограничения могут быть достаточны. Для блога, тяжелого изображения, который может получить внезапные шипы движения, риск трудно предсказать.

Страницы Cloudflare рекламируют неограниченную пропускную способность на своем бесплатном уровне. Это снижает стоимость и уменьшает затраты на контент для публичных сайтов, однако вам все равно нужно следовать политике приемлемого использования и платформы.

## Рабочий процесс и сотрудничество

Страницы облака создают предварительный просмотр размещения для ветвей и запросов, что помогает рецензентам проверять содержимое и макет перед объединением. GitHub Страницы проще, если вам нужна только одна ветка производства и не нужны среды обзора.

GitHub Pages имеет преимущество, когда вы хотите держать всё внутри GitHub. Для документации проекта с открытым исходным кодом установка знакома и близка к коду.

## Когда выбрать платформу

Choose GitHub Pages when you want the simplest GitHub native deployment for project documentation or a small personal site. Выберите Страницы Облака при ожидании непредсказуемого трафика, хотите установить предпросмотр, или могут потребоваться функции края позже.

Торговля является операционной сложностью: Облако добавляет другую платформу для управления, в то время как страницы GitHub поддерживают развертывание вблизи репозитория, но предлагают меньшее количество возможностей для совместной работы и краев. Подробнее об установке см. [Настройка репозитория CI/CD](/blog/configuring-your-repository-cicd/).
