Статический генератор сайта (SSG) компилирует файлы содержимого, шаблоны и активы в статический HTML, CSS и JavaScript перед внедрением. Вместо того чтобы отображать каждую страницу по каждому запросу, шаг сборки производит файлы, которые CDN или веб-сервер может доставлять напрямую.

## Как работает генератор статического сайта

```text
Содержимое (Markdown + передняя часть)
Шаблоны и компоненты
Активы и конфигурация
        <unk>
        <unk>
   SSG сборка
        <unk>
        <unk>
 public/ или dist/
        <unk>
        <unk>
   <unk> 
 CDN / статический хост
```

Типичная сборка состоит из четырех вещей:

1. Чтение содержимого: Parses Markdown и метаданные фронт-материи, такие как название, дата, теги и черновик статуса.
2. Применяет шаблоны: Карты содержимого для макетов страниц, списков, таксономий и фидов.
3. Генерирует вывод: Записывает HTML-страницы, RSS-ленты, карты сайтов и индексы поиска.
4. Копирует активы: перемещает изображения, шрифты и статические файлы в директорию для вывода.

## Преимущества и компромиссы

| Выгода                     | Почему важно                                                                  | Сделка                                                                    |
| :------------------------- | :---------------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| Быстрая доставка           | Предварительно собранные файлы могут быть переданы из кэша                    | Необходимо создать шаг до того, как изменения вступят в силу              |
| Меньшая поверхность взлета | Для страниц контента не требуется время выполнения приложения или база данных | Динамические функции нуждаются в API или на клиентской стороне JavaScript |
| Портабельность             | Содержание часто живет как обычные файлы Markdown                             | Шаблон и плагины экосистемы варьируются в зависимости от генерации        |
| Управление версией         | Контент и код могут жить в Git                                                | Редакторские рабочие процессы могут потребовать CMS слой                  |

Статические генераторы сайтов хорошо работают для блогов, документации, маркетинговых сайтов и портфолио. Они менее подходят в тех случаях, когда каждый запрос нуждается в персонализированной обработке данных на стороне сервера или в режиме реального времени.

## Общие статические генераторы сайта

Популярные SSG: Astro, Hugo, Zola, Eleventy, Jekyll, SvelteKit в статическом режиме. Для сравнения смотрите [Лучшие генераторы статических сайтов в 2026](/blog/best-static-site-generators/).

## Где подходят CMS на основе Git

SSG обрабатывает рендеринг. A Git based CMS handles authoring by giving editors a browser interface that commits Markdown to the repository. Эта комбинация сохраняет архитектуру доставки статически, делая редактирование контента доступным для неразработчиков. See [What Is a Git based CMS?](/blog/Git based-cms-explained/).
