使书写工具不受欢迎的最快方式是用你没有要求的生成的文本填写它。 [LightCMS](https://lightcms.me(https://lightcms.me ) AI copilot 的作用不同：模型有帮助，您保留对草稿的所有权。

它不是一个聊天窗口。这是一系列适合您已经编辑的文本的行动。

## 它做什么

选择一个段落，或者选择什么，复制件给你四个选项：

- **大纲**：将主题变成您可以接受、重新排序或删除的结构。
- **重语**：用不同的语音重写相同的想法。你可以收紧长句子，使笔记变得更加正式，或者放松一条严酷的线。
- **展开**：当你知道要说什么但不知道要写多少的话时，把一个简短的想法变成一个更完整的草案。
- **修复语法**：在您发布之前清理标点、语法和typpo。

每个结果都作为可编辑文本出现在文档中。您可以接受它，更改或撤消它。在您发布之前没有保存任何内容，在您阅读之前没有发布任何内容。

## 带上您自己的模型

LightCMS与任何OpenAI兼容的端点兼容。

| 提供商            | 为什么有人选择它             |
| :------------- | :------------------- |
| **OpenAI**     | 具有广泛能力的家庭模式          |
| **OpenRouter** | 许多模型的一个键，可以轻松切换      |
| **Groq**       | 快速推力和自由阶级            |
| **NVIDIA NIM** | 您可以自己运行的端点，包括GPU友好设置 |

由于LightCMS使用标准的 `/v1/chat/compltions` 格式，其他兼容的端点也可以工作。这包括一个 OpenAI-compatible 代理服务器后面的本地模型、私有网关或公司端点。

您的 API 密钥停留在您的 LightCMS 实例中。您发送的用于copilot动作的文本转到您配置的提供者。对于一个自托管、Apache-license的工具，该控制非常重要。

## 为什么它生活在编辑器中

聊天可以生成长的通用文本，您仍然需要粘贴、格式和重写。背景行动避免了这个问题。

- **小范围**：一个段落的改写有一个明确的结果。"写我一个博客文章"不是。
- **Formating stays integract**: copilot 在编辑器内运行, 所以列出逗留列表和前事项保持不变。
- **快速迭代**：如果您不喜欢结果，请重新生成选定的文本而不是整个文档。

这使得AI 感觉像一组小的编辑，更接近复制编辑器的工作方法。

## 负责任地使用它

- **写下自己的声音**：使用轮廓和扩展作为起点，然后保持像你一样的句子。
- **检查事实**：模型不知道你的代码、你的产品或你的数字。
- **将机密保存在提示之外**：您发送给一个提供商的任何东西都是该提供商可见的。

LightCMS只保存您批准的内容。它不会在后台生成内容，在LightCMS服务器上存储草稿，或使用您的草稿进行培训。

## 当它帮助大部分时

- **正在开始** ：大纲将空白页面变成你可以响应的草稿。
- **在末尾重写**：在你知道帖子的内容后突显导言。
- **最终清理**：在发布前几分钟内运行一个语法通道。

## 常见问题

### 我需要一个 API 密钥吗？

是的，要使用您需要在您的 LightCMS 实例中配置一个提供者。没有API密钥，编辑器中的所有其它东西都可以工作。

### 我的内容是否会被用于训练模型？

否。 LightCMS只将您选择的文本发送到您配置的端点。它不会将你的仓库或草稿发送到任何其他地方。

### 我能使用本地模型吗？

是。如果模型显示一个 OpenAI-compatible API，那么在该端点点点的 LightCMS 和复制器将以同样的方式工作。

### 它会改变我的前面事项吗？

否。 Copilot 操作只影响您选择的内容。

与 [voice-to-text](/blog/lightcms-voice-to-text/)配对，复制帮助了两边的起草工作：快速地将文字降落并将其塑造成一个易出版的文章。
