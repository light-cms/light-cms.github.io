[LightCMS](https://lightcms.me) — система управления контентом для публикации Markdown из Git. You write in a visual editor in your browser, and [LightCMS](https://lightcms.me) commits the Markdown file and its front matter to your repository. Ваш существующий конвейер CI/CD может затем построить и развернуть сайт.

## Проблема с LightCMS адресами

Статические генераторы сайтов могут упростить создание и развертывание сайта. Написание для одного менее удобно, если вы должны редактировать необработанный Markdown, формат переднего края или разобрать Git конфликты вручную.

[LightCMS](https://lightcms.me) дает авторам визуальный редактор, сохраняя содержимое в Git. Это соответствует тем группам, которые хотят Git собственности и обзора. Это отличный выбор из базы данных, поддерживаемой CMS с реальным сотрудничеством.

## Как LightCMS публикует контент

1. Войти через GitHub.
2. Подключите репозиторий к содержимому Markdown. Это может быть сайт построен с Astro, Hugo, Zola, 11ty, Jekyll, или Next.js.
3. Напишите в редакторе, который поддерживает заголовки, ссылки, таблицы, контрольные списки, блоки кода и средства массовой информации.
4. Опубликовать изменения. [LightCMS](https://lightcms.me) форматирует Markdown, обновляет переднюю часть и либо совершает коммиты в вашу ветку, либо открывает запрос на слияние для просмотра.
5. Ваш существующий CI/CD рабочий процесс, такой как действия GitHub, Cloudflare страницы, Vercel, или Netlify, может построить и развернуть сайт.

Так как публикация создает стандартный Git коммит, ваш сайт все еще может быть построен из репозитория, если вы перестаете использовать LightCMS.

## Технический профиль

| Атрибут                  | Реализация LightCMS                                                               |
| :----------------------- | :-------------------------------------------------------------------------------- |
| Хранилище                | Git репозиторий с файлами Markdown и фронт-телом                                  |
| Интерфейс редактора      | Визуальный редактор в вашем браузере                                              |
| Помощь ИИ                | Помощь редакторам в написании                                                     |
| Транскрипция голоса      | Редактор продиктования счетов                                                     |
| Обновление подписчика    | Интеграция с объявлением GitHub через [Newsy](https://github.com/light-cms/newsy) |
| Лицензирование и хостинг | Открытый исходный код и самохостинг                                               |
| Портабельность           | Содержимое остается в репозитории под вашим контролем                             |

## Когда LightCMS некорректный режим

LightCMS подходит для сайтов, которые сохраняют свой контент в Git и уже используют CI/CD для публикации. Рассмотрим другой инструмент, если:

- Вам нужны реляционные запросы, права пользователей или API контента в процессе выполнения. Безголовый CMS с базой данных, такой как [Payload](/comparison/lightcms-vs-payload-cms) или Strapi может быть лучше устроиться.
- Вы хотите, чтобы один сервис размещал публичный сайт. LightCMS не размещает его. Страницы с облаками, Vercel, Netlify, или S3 могут обслуживать построенный сайт.
- Вам нужен инструмент для отображения HTML-шаблонов. LightCMS это не делает; ваш генератор статических сайтов, таких как Hugo, Astro, или Zola, обрабатывает сборку.

Если вам нужно управление контентом на основе Git и визуальный редактор, Следующим шагом будет подключение тестового репозитория и подтверждение того, что LightCMS записывает переднюю сущность и Markdown в формате, который будет выглядеть как ваш статический генератор сайта.
