LightCMS 启动模板为您提供了一个预配置的静态站点存储库，以便您可以在不构建初始内容结构的情况下开始发布。 主题线路和部署从零开始。当您想要评估静态站点生成器或连接LightCMS到已知仓库布局时，它们是有用的。

## 启动模板应该包含

| 组件          | 为什么重要？             | 验证内容             |
| :---------- | :----------------- | :--------------- |
| 静态站点生成器配置   | 定义构建命令、内容目录和输出路径   | 生成器版本和配置文件格式     |
| 示例内容        | 显示前事项字段和Markdown结构 | 标题、日期、草稿、标签等必填字段 |
| 主题/布局       | 在您自定义设计前渲染帖子       | 许可和自定义限制         |
| CI/CD 工作流   | 提交时生成和部署           | 默认主机、 分支和密钥      |
| README/安装备注 | B. 说明当地的发展和部署      | 当前配刀精确度          |

## 如何使用模板

1. 选择一个生成器：根据您的团队的工具和网站需求选择Astro、Hugo、Zola、Eleventy、Jekyl、SwelteKit或Next.js。
2. 在 GitHub 中创建您的仓库：派生或使用模板存储库。
3. 本地运行网站：在连接CMS之前安装依赖关系并确认启动器构建。
4. 连接 LightCMS：位于仓库的 LightCMS 点和模板使用的内容目录。
5. 配置部署：确认构建命令、输出目录和主机提供者设置。

## 取销量

模板减少了设置时间，但也包括您可能需要撤销的意见。在启动前检查其依赖性、主题结构、许可和部署假设。当模板与目标生成器匹配时，它是一个很好的起点； 当您花费更多时间去除默认值而不是建立网站时，这是一个很差的起点。
