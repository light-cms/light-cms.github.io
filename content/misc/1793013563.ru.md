Страницы Cloudflare, Vercel, и Netlify могут размещать все современные веб-проекты, но они подходят для различных видов работы. Для большинства статических сайтов, страницы с облаком часто являются хорошей ценностью. Для Next.js-тяжелого приложения с серверным рендерингом, Vercel обычно самый простой вариант. Для сайта Jamstack, который хочет установить предпросмотры, функции и встроенные инструменты в одном месте, Netlify часто является хорошим средним выбором.

## Начните с того, что вам нужно

Перед тем, как сравнить функции, знайте, что вы планируете поместить в сети.

| Тип проекта                          | Хороший по умолчанию | Почему                                                |
| ------------------------------------ | -------------------- | ----------------------------------------------------- |
| Блог, документация, целевая страница | Страницы с облаком   | Быстрый статический хостинг с простой HTML-настройкой |
| Следующее .js/серверное приложение   | Версель              | Закрыть рамки и простые предпросмотры                 |
| Сайт Jamstack с формами/функциями    | Netlify              | Встроенные инструменты для установки Git              |

## Страницы с облаком

Страницы Cloudflare хорошо работают для статических сайтов и фронтэндов, которые используют отдельный бэкэнд. Он находится вблизи сети Cloudflare, и может связать его с другими службами, если вам это понадобится позже.

Главный трейдинг - это место, где запускается код. Если вы переместите код на Workers, он не запускается в стандартной настройке сервера Node.js. Это работает для многих заданий, но вам может потребоваться изменить свой код.

## Версель

Версель - хороший выбор, когда приложению нужны функции фреймворка, особенно серверного рендеринга, предварительного просмотра и оптимизации изображений. Для команд Next.js, как правило, легко перейти от Git к предварительному просмотру, а затем к производству.

Сделка стоит и подходят. Не выбирайте Vercel просто потому, что он популярен; посмотрите, насколько ваш проект нуждается в отображаемых сервером функциях. Перед отправкой реального трафика проверьте тарифный план.

## Netlify

Netlify хорошо работает для статических и Jamstack проектов, которые нуждаются в Git рабочий процесс и встроенные инструменты, такие как установка предварительных просмотров и безсерверных функций. Он сделал это на протяжении многих лет, так много фронтенд команды знают рабочий процесс.

## Простая проверка решения

Используйте эти три вопроса:

1. Это в основном статично? Начните с Cloudflare страниц.
2. Нужны ли серверные рендеринг или закрытие Next.js ниши? Рассмотрим Vercel.
3. Вы хотите статический хостинг со встроенными инструментами? Попробуйте Netlify.

Перед тем как выбрать, проверьте ограничения текущего тарифного плана каждого узла, правила использования бизнес-трафика и лимиты времени работы на официальных страницах ценообразования и документации. Детали хостинга могут измениться, поэтому подтвердите каждый лимит в собственном документе, а не полагаться на память.
