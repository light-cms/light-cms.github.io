Cloudflare Pages, Vercel, e Netlify podem hospedar projetos web modernos, mas eles se encaixam em diferentes tipos de trabalho. Para um site principalmente estático, as Páginas do Cloudflare são muitas vezes um bom valor. Para um aplicativo da Next.js com a renderização de servidores, Vercel geralmente é o ajuste mais fácil. Para um site Jamstack que quer implantar pré-visualizações, funções e ferramentas integradas em um só lugar, Netlify muitas vezes é uma boa escolha do meio.

## Comece com o que você precisa

Antes de comparar recursos, saiba o que você planeja colocar online.

| Tipo do projeto                       | Bom padrão            | Porquê                                                              |
| ------------------------------------- | --------------------- | ------------------------------------------------------------------- |
| Blog, documentos, página inicial      | Páginas do Cloudflare | Hospedagem estática rápida com configuração de arquivo HTML simples |
| App Next.js/server-rendered           | Transportadora        | Fechar laços de estrutura e pré-visualizações fáceis                |
| Jamstack site com formulários/funções | Netlify               | Ferramentas integradas para implantações Git                        |

## Páginas do Cloudflare

Cloudflare Pages funciona bem para sites estáticos e frontend que usam um backend separado. Está perto da rede de fronteiras da Cloudflare e pode ligar a seus outros serviços se precisar deles mais tarde.

O código principal é onde é executado Se você mover a alteração do código para os Workers, ele não será executado em uma configuração padrão de servidor Node.js. Isto funciona para muitas tarefas de aresta, mas você pode precisar alterar seu código.

## Transportadora

Vercel é uma boa escolha quando seu aplicativo necessita de recursos de framework, especialmente processamento de servidor, pré-visualização de implantações e otimização de imagem. Para as equipes do Next.js, é geralmente fácil passar de um Git push para uma visualização e depois para produção.

O compromisso é de custo e adequado. Não selecione Vercel só porque é popular; veja se o seu projeto precisa de recursos renderizados pelo servidor. Verifique o plano de preços antes de enviar tráfego ao vivo.

## Netlify

O Netlify funciona bem para projetos estáticos e Jamstack que precisam de um fluxo de trabalho Git e ferramentas incorporadas, como pré-visualizações de deploy e funções de não-servidor. Há anos que o fazem, pelo que muitas equipas de frontend conhecem o fluxo de trabalho.

## Uma simples verificação de decisão

Use estas três perguntas:

1. Será isto estático, na sua maior parte, Comece com as páginas Cloudflare.
2. Ele precisa de renderização ou fechar os blocos Next.js? Considere Vercel.
3. Você quer hospedagem estática com ferramentas incorporadas? Experimente Netlify.

Antes de escolher, verifique os limites do plano atual de cada host, regras de uso de negócio, custos de largura de banda e limites de tempo de execução em suas páginas de preços e documentos oficiais. Detalhes de hospedagem podem mudar, então confirme cada limite na documentação do próprio host em vez de depender da memória.
