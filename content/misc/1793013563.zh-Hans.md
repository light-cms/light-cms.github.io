对于大多数项目，正确的选择取决于你正在构建什么：

- **Cloudflare Pages** 是一个强大的适合静态站点，需要快速的全球投递和慷慨的带宽。
- **Vercel** 是一个非常适合服务器渲染的应用程序和团队，他们想要一个经过磨盘的预览和部署工作流。
- **Netlify** 是静态站点和受益于内置平台功能的 Jamstack 项目的一个固态全屋顶。

没有一个普遍获胜者。承付前检查当前价格和限额，因为免费等级和超额规则会发生变化。

## 云端页面

\*\*最好：\*\*博客、文档、登陆页面和使用 API 的前端应用程序分开托管。

云端页面提供快速的全球投递、静态托管和云端服务，如工人、R2和D1。

**交易：** 动态应用程序通常需要 Cloudflare 工人，运行时间不同于常规的 Node.js 服务器。

## Vercel

**最适合：** 服务器渲染的应用程序和团队，它们对部署的预览和抛光的开发者体验。

Vercel很好地与框架和部署工作流整合，包括服务器渲染、图像优化和预览部署。

**互换：** 爱好等级不是用于商业用途，付费计划带宽或使用成本可能在高流量项目中快速上升。在选择计划生产前审查当前计划的细节。

## 网络化

**最佳：** 静态站点、Astro项目、Jamstack站点和希望以内置工作流进行基于 Git的部署的团队。

Netlify提供成熟的 Git 部署，部署预览，无服务器功能和平台功能，以减少额外服务的需求。

**交易：** 它的边缘可能小于云端的静态主机或Next.js-first 开发的 Vercel。

## 定价备注

Cloudflare页面包含免费提供的无限静态资产请求。 Vercel使用基于计划的津贴和使用费。 Netlify使用基于信用的部署、带宽、请求和计算模型。总是在每个供应商的定价页面确认最新的计划细节。
