Блог стоит начинать, когда у вас есть что-то специфичное для преподавания, объясните, или документируйте для будущего вас или кого-то в той же обуви, как вы. Интернет не требует другого общего поста, написанного для всех. Нужна четкая заметка от людей, решивших настоящую проблему и потративших время на ее запись.

## Держите настройки публикации простыми

Для многих личных блогов, журналов проектов и технических заметок достаточно статического сайта. Вы записываете Markdown, строите HTML и устанавливаете файлы на хост. Нет базы данных для поддержания и отсутствия CMS для обновления только для публикации пост.

If you want a browser-based editor on top of that workflow, a Git based CMS can help. Вы все еще получаете файлы в вашем репозитории, но вам не нужно каждый раз редактировать фронт-дело вручную.
