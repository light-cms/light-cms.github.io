Un blog vale la pena comenzar cuando tienes algo específico para enseñar, explicar, o documento para el futuro usted o alguien en los mismos zapatos como usted. Internet no necesita otro post genérico escrito para todos. Necesita notas claras de personas que resolvieron un problema real y se tomaron el tiempo de escribirlo.

## Mantener la configuración de publicación simple

Para muchos blogs personales, registros de proyectos y notas técnicas, un sitio estático es suficiente. Escribes Markdown, construyes HTML y implementas los archivos en un host. No hay ninguna base de datos para mantener y no hay tiempo de ejecución CMS para parchear sólo para publicar un post.

If you want a browser-based editor on top of that workflow, a Git based CMS can help. Usted todavía obtiene archivos en su repositorio, pero no tiene que editar la materia principal a mano cada vez.
