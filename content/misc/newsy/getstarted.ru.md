Запуск рассылки по электронной почте для статического блога заставляет вас управлять SMTP-серверами, обработкой отказов и базой подписчиков. [Newsy](https://newsy.lightcms.me) пропускает это сверху, запустив вашу рассылку в GitHub репозитории.

Utterances, Giscus, и Gitalk использовали проблемы GitHub для приведения комментариев к статическим сайтам без бэкэнда. Newsy применяет ту же идею к новостным бюллетеням: подписчики и сообщения в прямом эфире вместе с вашим кодом. Торговля заключается в том, что читателям нужна учетная запись на GitHub.

## Что запускает рассылка на GitHub

1. Ваш информационный бюллетень живет вместе с кодом вашего сайта в том же репозитории.
2. GitHub отслеживает подписчиков и уведомлений без отдельной базы данных.
3. Вы не управляете почтовыми серверами, записями SPF/DKIM и квотами по электронной почте.
4. Вы можете запустить файл Go на безсерверных платформах, таких как Vercel или AWS Lambda, или скомпилируйте его в WebAssembly с помощью [TinyGo](https://tinygo.org/) для запуска JavaScript и TypeScript.

Если вы предпочитаете смотреть за чтением, то в [видео-гиде](/misc/newsy/video/).

## Размещайте вашего бота

Выполните следующие шаги, чтобы запустить Newsy локально и подключить его к вашим репозиториям GitHub.

### 1. Клонировать репозиторий

```bash
git clone git@github.com:light-cms/newsy.git
cd newsy
```

### 2. Настроить окружение

Новая версия использует [mise](https://mise.jdx.dev) для управления зависимостями инструментальных средств:

```bash
mise deps
```

### 3. Создать и запустить

Создайте и запустите двоичный файл:

```bash
перейти к сборке
./newsy
```

### 4. Configure the GitHub App

1. Откройте `http://localhost:3000` в браузере.
2. Если вам нужно раскрыть свой локальный сервер, используйте туннельный сервис, например [ngrok](https://ngrok.com), [Туннель Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/) или туннель SSH через [localhost.run](https://localhost.run/):

   ```bash
   ssh -R 80:localhost:3000 localhost.run
   ```

3. Откройте URL туннеля (например, `https://xyz.localhost.run`) в вашем браузере.

   [![Установка Ньюси сквозь](https://markdown-videos-api.jorgenkh.no/youtube/sfjo6ZVgC9w.gif?duration=600)](https://youtu.be/sfjo6ZVgC9w)

   Если вы столкнулись с проблемами, проверьте [видео-гид](/misc/newsy/video/) или переключитесь на другого поставщика туннелей.

4. Выберите уникальное имя приложения.
5. Вставьте URL туннеля в поле URL Webhook и отправьте его.
6. Храните файл `.env`, сгенерированный в корневом каталоге вашего проекта. Он должен выглядеть следующим образом:

```bash
APP_ID=""
WEBHOOK_SECRET=""
PRIVATE_KEY=""
DATABASE_URL=""
```

> [!IMPORTANT]
> Install the GitHub App on selected repositories only, rather than on "All repositories".

Вы можете поделиться одним экземпляром Newsy с несколькими репозиториями или пользователями.

> [!ПРИМЕЧАНИЕ]
> По умолчанию Newsy создает объявления при добавлении новых файлов контента (`.html`, `.md`, `.mdx`), а не при редактировании существующих.

## Развертывание в Vercel или безсерверное время выполнения

Вы можете развернуть репозиторий Newsy непосредственно в Vercel или любой безсерверный хост, поддерживающий бинарные файлы Go. Если целевое время выполнения запускается только JavaScript или TypeScript, то скомпилируйте Newsy в WebAssembly с [TinyGo](https://tinygo.org/). Бесплатные уровни на Vercel и подобных платформах обычно достаточно для личных блогов.

## Подписаться на демо-рассылку

Вы можете протестировать поток читателя, подписавшись на демо-репозиторий: [Подписаться на GitHub](https://github.com/Pratyay360/blogs_md/issues/1).

## Создать кнопку подписки

Сгенерируйте для вашей учетной записи кнопку inline-подписки на сайте [newsy.lightcms.me](https://newsy.lightcms.me/) и, при необходимости, стирайте ее с помощью [Primer CSS](https://cdnjs.com/libraries/Primer).

> [!TIP]
> После того, как бот опубликовал свой первый выпуск новости, заблокировать разговор, чтобы читатели могли подписаться без добавления комментариев к теме.
