Newsy benötigt ein kleines Set von GitHub App-Berechtigungen, damit es Änderungen von Inhalten beobachten und Newsletter-Updates posten kann.

[![GitHub App Einstellungen mit Newsy Berechtigungen](https://i.ibb.co/F44T76gt/Screenshot-2026-08-22-at-13-11-31-Git-Hub-App-settings-newsletterpratyay-af.png)](https://i.ibb.co/F44T76gt/Screenshot-2026-08-22-at-13-11-31-Git-Hub-App-settings-newsletterpratyay-af.png)

Falls etwas nicht wie erwartet funktioniert, überprüfen Sie zuerst die App-Berechtigungen. Sie können auch Probleme im [Newsy Repository](https://github.com/light-cms/newsy) melden.
