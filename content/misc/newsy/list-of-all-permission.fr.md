Newsy a besoin d'un petit ensemble d'autorisations pour l'application GitHub afin de pouvoir surveiller les changements de contenu et les mises à jour de la newsletter.

[![Paramètres de l'application GitHub montrant les autorisations de Newsy](https://i.ibb.co/F44T76gt/Screenshot-2026-08-22-at-13-11-31-Git-Hub-App-settings-newsletterpratyay-af.png)](https://i.ibb.co/F44T76gt/Screenshot-2026-08-22-at-13-11-31-Git-Hub-App-settings-newsletterpratyay-af.png)

Si quelque chose ne fonctionne pas comme prévu, vérifiez d'abord les autorisations de l'application. Vous pouvez également signaler des problèmes dans le [dépôt Newsy] (https://github.com/light-cms/newsy).
