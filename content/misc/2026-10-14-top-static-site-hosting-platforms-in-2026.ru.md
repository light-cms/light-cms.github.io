Большинство статических хостов сайта могут размещать Astro, Hugo, Jekyll, Eleventy, или Zola сайта в течение нескольких минут. Реальные различия отображаются после вашего первого развертывания: ограничения пропускной способности, квоты сборки, просмотр рабочих процессов, правил коммерческого использования, а также того, что происходит, когда ваш сайт нуждается в функциях на сервере.

## Как сравниваются статические узлы

| Хост               | Хороший подбор                                                                    | Главный трейд-офф                                                                 |
| :----------------- | :-------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| GitHub Pages       | Публичные сайты проектов уже на GitHub                                            | Ограниченные возможности платформы и ограничения использования                    |
| Страницы с облаком | Статические сайты с переменным трафиком                                           | Перекрытие и разделение функцией Cloudflare Workers                               |
| Версель            | Интерфейс приложений, нуждающихся в предпросмотре и интеграции фреймворка         | Необходимо уделять внимание плановым ограничениям и коммерческим правилам         |
| Netlify            | Сайты Jamstack, нуждающиеся в форме, функциях и предпросмотре                     | Цены на кредит и использование могут быть сложнее прогнозировать                  |
| Хирург             | Первое статическое развертывание и быстрое демо                                   | Меньше командных рабочих процессов и возможностей панели управления CI/CD         |
| Осколочный край    | Эксперименты, требующие использования WebAssembly или пользовательских приложений | Экосистема маленькой статики сайта                                                |
| Deno Deploy        | Существующие развёрнутые развёртки JavaScript/TypeScript                          | Необходимо сначала проверить статус платформы и руководящие указания по миграции. |

Каждый из вышеуказанных параметров надежно служит HTML и CSS, так что ваш выбор обычно сводится к предсказуемости биллинга и количеству поведения на стороне сервера вы планируете добавить позже.

## GitHub Pages

GitHub Страницы являются самым простым выбором, когда ваш репозиторий уже живет на GitHub и вы хотите, чтобы публичный сайт для документации, страницы проекта или персональный блог. Перед тем как размещать на нем коммерческие сайты, проверьте текущие ограничения и правила использования GitHub.

## Страницы с облаком

Cloudflare Pages works well for static sites that need global CDN delivery and Git based deploys without worrying about static asset bandwidth spikes. Если вы планируете добавить функции на стороне сервера позже, проверьте текущее руководство Cloudflare по страницам, функциям и Рабочим перед блокировкой вашей настройки.

## Версель

Vercel соответствует командам фронтэндов, которые полагаются на развертывание предварительного просмотра запросов и жесткую интеграцию с системой. Часто это самый простой путь для Next.js проектов, хотя и хорошо размещает простые статические сайты. Убедитесь, что ваш ожидаемый трафик и коммерческое использование соответствуют выбранному вами уровню плана.

## Netlify

Netlify имеет смысл, когда вы хотите создать хостинг вместе с пред-просмотрами, формами, безсерверными функциями или идентификацией в одном месте. Прогнозируемость трафика зависит от затрат: проверьте, как его кредитная модель и модель использования применима к вашему трафику и минутам сборки перед принятием.

## Хирург

Surge.sh это статический хост, управляемый CLI, созданный для быстрой и прямой загрузки с вашего терминала. Он работает хорошо для быстрых демов и простых статических сайтов, когда вам не нужны полные CI/CD панели управления или командной строки обзора.

## Осколочный край

Основное внимание в работе с Wasmer Edge уделяется развертыванию систем WebAssembly и многократного времени. Для стандартного статического блога, скорее всего, это больше платформы, чем вам нужно, хотя и стоит оценить, опирается ли ваш проект на свою модель рабочего времени.

## Deno Deploy

Deno Deploy используется для рабочих загрузок JavaScript и TypeScript на крае. Прежде чем начать новый долгосрочный проект, проверьте текущее состояние платформы Deno и руководство по миграции.

### Сопоставление узла с вашим сайтом

- Простая публичная документация или личный блог: GitHub страницы, облачные страницы или Surge.sh.
- Интерфейс приложения с предварительным запросом и безсерверными функциями: Vercel или Netlify.
- Статический сайт, который может вырасти в краеугольные вычисления позже: Облачные страницы и Рабочие страницы.

Перед переходом на сайт проверьте текущую страницу провайдера, ограничения по тарифам, коммерческую политику, квоты для построения и поддержку фреймворка. Хост, который бесплатно для небольшого демо, может стать дорогостоящим или ограничительным после того, как ваш сайт станет реальным траффиком.
