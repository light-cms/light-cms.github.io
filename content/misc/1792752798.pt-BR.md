Vale a pena começar um blog quando você tiver algo específico para ensinar, explicar, ou documento para o futuro você ou alguém nos mesmos sapatos como você. A internet não precisa de outro post genérico escrito para todos. Precisa, de facto, de notas claras por parte de pessoas que resolveram um problema real e que levaram tempo a escrevê-lo.

## Mantenha a configuração de publicação simples

Para muitos blogs pessoais, logs de projetos e notas técnicas, um site estático é suficiente. Você escreve Markdown, constrói HTML e faz o deploy dos arquivos em um host. Não há banco de dados para manter e não há nenhum tempo de execução de CMS para fazer a atualização apenas para publicar uma publicação.

If you want a browser-based editor on top of that workflow, a Git based CMS can help. Ainda há arquivos em seu repositório, mas você não precisa editar a questão frontal manualmente todas as vezes.
