Cloudflare Pages, Vercel, und Netlify können alle moderne Web-Projekte hosten, passen aber zu verschiedenen Arbeitsarten. Für eine meist statische Website ist Cloudflare Seiten oft sehr wertvoll. Für eine Next.js-schwere App mit Serverrendering ist Vercel normalerweise die einfachste Wahl. Für eine Jamstack-Website, die Vorschau, Funktionen und eingebaute Werkzeuge an einem Ort bereitstellen möchte, ist Netlify oft eine gute Mittelauswahl.

## Beginnen Sie mit dem, was Sie brauchen

Bevor Sie die Funktionen vergleichen, wissen, was Sie online stellen wollen.

| Projekttyp                               | Gut Standard      | Warum                                                                 |
| ---------------------------------------- | ----------------- | --------------------------------------------------------------------- |
| Blog, docs, Landingpage                  | Cloudflare-Seiten | Schnelles statisches Hosting mit einfacher Einrichtung der HTML-Datei |
| Nächste.js/server-gerenderte App         | Verneigen         | Framework-Verbindungen und einfache Vorschau schließen                |
| Jamstack-Seite mit Formularen/Funktionen | Deno Deploy       | Integrierte Werkzeuge für Git-Deploys                                 |

## Cloudflare-Seiten

Cloudflare Pages funktioniert gut für statische Seiten und Frontends, die ein separates Backend verwenden. Es befindet sich in der Nähe von Cloudflare’s Kantennetz und kann mit seinen anderen Diensten verbunden werden, wenn Sie diese später benötigen.

Der Hauptstreit ist, wo der Code läuft. Wenn Sie den Code auf den Worker verschieben, läuft er nicht in einem Standard-Setup des Node.js Servers. Dies funktioniert bei vielen Aufgaben am Rand aber Sie müssen möglicherweise Ihren Code ändern.

## Verneigen

Vercel ist eine gute Wahl, wenn Ihre App Framework-Funktionen, insbesondere Server-Rendering, Vorschau-Deployments und Bildoptimierung benötigt. Für Next.js Teams ist es in der Regel einfach, von einem Git Push zu einer Vorschau und dann zur Produktion zu gehen.

Der Ausgleich ist kosten- und passend. Wählen Sie Vercel nicht aus, nur weil es beliebt ist; schauen Sie, ob Ihr Projekt serverseitig gerenderte Funktionen benötigt. Überprüfen Sie den Preisplan, bevor Sie Live-Traffic senden.

## Deno Deploy

Netlify funktioniert gut für statische und Jamstack-Projekte, die einen Git-Workflow und eingebaute Werkzeuge wie das Bereitstellen von Vorschaubildern und serverlosen Funktionen benötigen. Es hat dies seit Jahren getan, so viele Frontend-Teams kennen den Workflow.

## Eine einfache Entscheidungsprüfung

Benutzen Sie diese drei Fragen:

1. Ist das meistens statisch? Beginnen Sie mit den Cloudflare Seiten.
2. Benötigt es Server-Rendering oder Schließen von Next.js Bindungen? Man denke an Vercel.
3. Wollen Sie ein statisches Hosting mit integrierten Werkzeugen? Testen Sie Netlify.

Überprüfen Sie vor Ihrer Wahl die aktuellen Planungsgrenzen, Geschäftsnutzungsregeln, Bandbreitenkosten und Laufzeitbeschränkungen auf den offiziellen Seiten und Dokumenten. Hosting Details können sich ändern, so bestätigen Sie jede Grenze in der Dokumentation des Hosts, anstatt sich auf den Speicher zu verlassen.
