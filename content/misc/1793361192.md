Writing and maintaining documentation is as important as building the product.

For documentation sites, many teams choose tools like [Astro Starlight](https://starlight.astro.build/), [Hugo](https://gohugo.io/), [VitePress](https://vitepress.dev/), [Eleventy](https://www.11ty.dev/), or [Docsy](https://www.docsy.dev/). For writing, tools like [Obsidian](https://obsidian.md/) are common.

We already use AI copilots to write, debug, and ship code. Documentation can benefit from the same kind of help: fixing small mistakes, refining drafts, keeping structure clear, and making updates easier to publish.

Many documentation tools use Markdown with front matter. If your blog and docs already use that format, it can make sense to manage them with the same editor and workflow.
