Statische Site-Generatoren sind einfach zu mögen, sobald sie eingerichtet sind. Für sie zu schreiben, kann eine andere Geschichte sein. Ein schneller Beitrag sollte nicht das Öffnen eines Code-Editors erfordern, das Beheben der Frontmasse und das Drücken eines Git-Commits erfordern.

Wir haben [LightCMS](https://www.lightcms.me/), so dass du in einem Browser schreiben kannst und jeden Beitrag als Markdown Datei in deinem eigenen GitHub Repository behalten kannst. Diese Seite ist unser Notizbuch, während wir LightCMS bauen. Wir schreiben darüber, was funktioniert, wo das Publizieren von Git schwierig wird und was es braucht, um verschiedene statische Site-Tools zu pflegen.
