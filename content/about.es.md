Los generadores estáticos de sitios son fáciles de gustar una vez que están configurados. Escribir para ellos puede ser una historia diferente. Un mensaje rápido no debería requerir abrir un editor de código, arreglar la materia frontal y empujar un commit de Git.

Hemos creado [LightCMS](https://www.lightcms.me/) para que puedas escribir en un navegador y mantener cada publicación como un archivo Markdown en tu propio repositorio de GitHub. Este sitio es nuestro cuaderno mientras construimos LightCMS. Escribimos sobre lo que funciona, donde la publicación de Git se vuelve incómoda y lo que se necesita para mantener diferentes herramientas estáticas del sitio.
