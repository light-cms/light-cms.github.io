Geradores de site estáticos são fáceis de gostar quando estão instalados. Escrever para eles pode ser uma história diferente. Uma postagem rápida não deve exigir a abertura de um editor de código, a correção de um objeto front, e o envio de um commit Git.

Criamos [LightCMS](https://www.lightcms.me/) para que você possa escrever em um navegador e manter cada post como um arquivo Markdown no seu próprio repositório GitHub. Este site é nosso caderno à medida que construímos o LightCMS. Escrevemos sobre o que funciona, onde a publicação do Git fica estranha, e o que é preciso para manter diferentes ferramentas de site estático.
