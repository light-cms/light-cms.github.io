Pages CMS is a Git based CMS focused on simple form-based editing over repository content. Los equipos buscan alternativas cuando necesitan interfaces de escritura richer. Edición visual, esquemas más fuertes, soporte de Git multiproveedor o alojamiento administrado.

## Alternativas de un vistazo

| Alternativo    | Mejor ajuste                                                             | Clave de desconexión                                                      |
| :------------- | :----------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| LightCMS       | Edición de Markdown visual para sitios estáticos                         | Verificar el conjunto actual de características y opciones de alojamiento |
| Decaer CMS     | Established Git based CMS with config-driven collections                 | El flujo de trabajo UI/config puede sentirse fechado para escritores      |
| TinaCMS        | Edición visual o estructurada con sincronización de Git                  | Requiere decisiones de esquema/configuración                              |
| Llave estática | Esquemas de contenido de primera línea local orientados al desarrollador | Menos centrado en escritores                                              |
| Sveltia CMS    | Interfaz de navegador ligera basada en CMS                               | Proyecto: verificar la madurez                                            |
| Cañón nube     | Edición visual gestionada para equipos/agencias                          | Precios comerciales                                                       |

## Criterios de selección

Al comparar las alternativas CMS de Páginas, evaluar:

- Experiencia de edición: campos de formulario, WYSIWYG o edición en página.
- Soporte de proveedor de Git: GitHub sólo o también GitLab/Bitbucket.
- Modelo de contenido: Materia/formas delanteras, esquemas escritos o bloques estructurados.
- Manejo de medios: cargas, rutas de activos y almacenamiento externo.
- Modelo operativo: SaaS alojado, aplicación autoalojada o interfaz de administración estática.

Para equipos que ya utilizan Markdown in Git, la migración es a menudo posible sin mover contenido. El trabajo principal es mapear campos, rutas de medios y flujo de trabajo editorial.
