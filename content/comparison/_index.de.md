Ehrlich, Seite an Seite schreibt [LightCMS](https://lightcms.me) gegen das Feld. Jede einzelne beginnt bei der Architektur (wo Inhalte leben, was auf Anfrage läuft) und endet damit, wer sie eigentlich aussuchen soll.

**Versus kopflose Plattformen**: [Sanity](/comparison/lightcms-vs-sanity), [Contentful](/comparison/lightcms-vs-contentful), [Storyblok](/comparison/lightcms-vs-storyblok), [Strapi](/comparison/lightcms-vs-strapi), [Payload](/comparison/lightcms-vs-payload-cms).

**Versus Git basierte Editoren**: [Decap CMS](/comparison/lightcms-vs-decap-cms), [TinaCMS](/comparison/lightcms-vs-tinacms), [Keystatic](/comparison/lightcms-vs-keystatic), [Seiten CMS](/comparison/lightcms-vs-pagescms).

**Versus traditionelles CMS und Builders**: [WordPress](/comparison/lightcms-vs-wordpress), [Drupal](/comparison/lightcms-vs-drupal), [Joomla](/comparison/lightcms-vs-joomla), [Ghost](/comparison/lightcms-vs-ghost), [Webflow](/comparison/lightcms-vs-webflow).

**Anleitungen**: [Top Git basierte CMS-Plattformen](/comparison/top-git-cms), [Decap Alternativen](/comparison/netlifycms), [Seiten CMS Alternativen](/comparison/pagescms), [GitCMS](/comparison/gitcms-a-git-based-cms-built-for-ai-era-websites).
