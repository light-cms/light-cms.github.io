LightCMS et Ghost supportent la publication, mais ils sont construits pour différents résultats. LightCMS est un flux de travail basé sur Git pour le contenu statique du site. Ghost est une plateforme de publication avec des fonctionnalités intégrées d'adhésion, d'abonnement et de newsletter.

## Comparaison

| Zone de stockage    | LightCMS                                       | Fantôme                                          |
| :------------------ | :--------------------------------------------- | :----------------------------------------------- |
| Architecture        | Contenu basé sur Git + build statique          | Application + plateforme de base de données      |
| Force primaire      | Flux de contenu du site statique               | Fonctionnalités commerciales de publication      |
| Adhésions/paiements | Ce n'est pas une fonctionnalité CMS principale | Adhésions/abonnements natifs                     |
| Newsletters         | Dépend du workflow/intégration externe         | Fonctionnalités de la newsletter native          |
| Hébergement         | Hôte/CDN statique                              | Hébergement fantôme ou application auto-hébergée |

## Choix entre eux

Ghost est un choix fort lorsque votre publication est aussi votre entreprise. Si les adhésions, les abonnements payants et les newsletters natives sont au cœur de ce que vous faites, Ghost a intégré ces éléments.

LightCMS est plus adapté lorsque votre site est principalement contenu. Vous obtenez Markdown dans Git, livraison statique, et une configuration plus simple. Vous pouvez utiliser des services externes pour les bulletins d'information ou les adhésions, mais vous le ferez vous-même.

La question est donc assez simple: dirigez-vous une publication, ou une entreprise d'audience? Voir [LightCMS vs WordPress](/comparison/lightcms-vs-wordpress) et [Best CMS for Static Sites](/blog/best-cms-for-static-sites/).
