Storyblok und LightCMS nennen sich beide visuelle Editoren, aber sie sind auf unterschiedliche Weise visuell. Storyblok erlaubt es dir, Seiten aus Blöcken zu erstellen und das Layout während du bearbeitest. LightCMS bietet Ihnen einen sauberen Dokumenten-Editor zum Schreiben von Artikeln, die als Markdown in Ihrem Git-Repository enden.

Die richtige Wahl hängt davon ab, was Sie machen. Eine Landingpage aus wiederverwendbaren Komponenten benötigt ein anderes Werkzeug als einen 1.500 Wort-Blog-Beitrag mit Code-Beispielen und Screenshots.

## So funktionieren sie

Storyblok ist ein kopfloses CMS. Inhalte werden als Blöcke modelliert, in einer visuellen Vorschau bearbeitet und über eine API geliefert. Ihr Frontend holt diesen Inhalt ab und gibt ihn aus.

LightCMS is a Git based writing workspace. Inhalte werden als Markdown Dateien mit Frontmatter in Ihrem Projektarchiv gespeichert. Sie schreiben in einem Dokumenten-Editor, übertragen die Änderungen, und Ihr statischer Site-Generator erstellt die Website.

|                 | LightCMS                              | Storyblok                                     |
| --------------- | ------------------------------------- | --------------------------------------------- |
| Inhaltsspeicher | Dateien in Ihrem Git-Repository       | Gehostetes CMS                                |
| Lieferung       | Statisches Build zu CDN               | Content API                                   |
| Stil bearbeiten | Dokument zuerst schreiben             | Blockbasierte Bearbeitung der visuellen Seite |
| Beste für       | Beiträge, Bilder, Änderungsprotokolle | Startseiten, komponentengesteuerte Seiten     |
| Vorschau        | Nach der Erstellung/Seitenvorschau    | Visuelle Live-Vorschau                        |
| Preis           | Selbstgehostet, keine Lizenzgebühr    | Planbasierte SaaS                             |

## Wenn Storyblok mehr Sinn macht

Storyblok leuchtet, wenn die Seite selbst das Produkt ist. Wenn sich die Vermarkter um einen Helden, ein Raster, Zeugnisse oder eine CTA bewegen müssen, ohne einen Entwickler zu fragen, macht ein Block-basierter visueller Editor Sinn. Live-Vorschau hilft beim Layout ebenso wie bei der Kopie.

## Wenn LightCMS mehr Sinn macht

LightCMS leuchtet, wenn das Schreiben ist das Produkt. Lange Artikel in einem Block-Editor können sich unbeholfen fühlen. In einem Dokumenten-Editor schreiben Sie einfach: Überschriften, Listen, Tabellen, Bilder, Code, alles im Fluss. Das Ergebnis ist schlicht Markdown in Git, die Ihre Inhalte portabel und Ihre Website einfach als statische Dateien zu veröffentlichen.

## Wählen Sie zwischen ihnen

Wähle Storyblok, wenn dein Team Seiten visuell erstellen und ordnen muss. Wählen Sie LightCMS aus, wenn Ihr Team hauptsächlich Artikel und Dokumente veröffentlicht und eine ruhigere Schreiberfahrung wünscht.

Wenn Sie im Zaun sind, schauen Sie sich die letzten zehn veröffentlichten Seiten an. Wenn es sich bei den meisten um strukturierte Marketingseiten handelt, passt Storyblok. Wenn die meisten Artikel oder Doktoren sind, wird sich LightCMS wahrscheinlich besser fühlen.
