LightCMS und Contentful zielen auf verschiedene Anwendungsfälle. LightCMS ist für Git basiertes statisches Site-Publishing konzipiert, in dem Inhalte in einem Repository leben und als statische Dateien eingesetzt werden. Contentful ist ein kopfloses CMS ohne Unternehmen, das strukturierte Inhalte über APIs für Websites, Apps und andere Kanäle bereitstellt.

## Vergleich

| Fläche          | LightCMS                                 | Inhaltlich                                            |
| :-------------- | :--------------------------------------- | :---------------------------------------------------- |
| Primärmodell    | Git basiertes CMS für statische Seiten   | SaaS kopflose CMS                                     |
| Inhaltsspeicher | Repository Markdown/Dateien              | Herstellerverwaltete Inhaltsplattform                 |
| Lieferung       | Statische Build-Ausgabe                  | Inhalts-APIs                                          |
| Beste Passung   | Blogs, Docs, Marketing-Seiten            | Mehrkanalinhaltsvorgänge                              |
| Governance      | Git-Workflows, PRs, Repo-Berechtigungen  | Rollen, Workflows, Umgebungen, Lokalisierung          |
| Kostenmodell    | Produkt-/Selbst-Hosting-Kosten variieren | Abonnement/Nutzung/Sitzplatz-basierte Preisgestaltung |

## Wählen Sie zwischen ihnen

Contentful macht Sinn, wenn dieselben Inhalte über mehrere Kanäle reisen müssen und Sie eine Unternehmensführung benötigen, Workflows, oder eine verwaltete Plattform mit APIs und SLAs.

LightCMS macht mehr Sinn, wenn Ihre Hauptausgabe ist eine statische Website und Sie wollen Inhalte leben in Git. Sie erhalten eine einfachere Publishing-Einrichtung, aber Sie erhalten nicht die gleiche Enterprise Content Operations Layer.

Es geht um Skalierung und Form. Wenn Sie Inhalte in Teams, Produkten und Kanälen betreiben, kann Contentful die Kosten und die Händlersperre rechtfertigen. Wenn Sie eine Website veröffentlichen, ist Markdown im Projektarchiv in der Regel ruhiger und billiger zu bedienen.
