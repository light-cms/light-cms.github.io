[GitCMS](https://gitcms.dev) ist ein Git-basiertes CMS, das um Menschen herum positioniert und KI bei der Bearbeitung von Webseiten unterstützt wird. Wie andere Git-basierte CMS-Tools behält es Inhalte in einem Repository und verwendet Commits als Publishing-Mechanismus. Sein Differenzator ist ein Schwerpunkt auf überprüfbaren Workflows für agent-generierte Änderungen.

## Wo GitCMS passt

| Fläche              | GitCMS-Fokus                                                | Traden aus                                                        |
| :------------------ | :---------------------------------------------------------- | :---------------------------------------------------------------- |
| Inhaltsspeicher     | Git Repository als Quelle der Wahrheit                      | Noch benötigt Git/CI/CD Setup                                     |
| Workflow bearbeiten | Visual/redaktionelle Ebene über Repository-Dateien          | Verbessertes Ökosystem als etablierte CMS-Optionen                |
| KI-Workflows        | Entworfen für menschliche Überprüfung von Agentenänderungen | Kann für Solo-Autoren unnötig sein                                |
| Preis/Lizenzierung  | Kostenloser Status plus bezahlter Tarife                    | Nicht dasselbe wie vollständig Open-Source-selbst-gehostete Tools |

## Wann GitCMS berücksichtigt werden soll

GitCMS ist es wert, zu bewerten, ob KI-Agenten oder automatisierte Tools regelmäßig Änderungen an Ihrer Website vorschlagen und Sie benötigen einen redaktionellen Review-Layer, bevor Sie veröffentlichen. Für Teams, die nur eine einfache manuelle Bearbeitung von Markdown in GitHub benötigen, können leichtere Tools wie Pages CMS oder Decap CMS ausreichen.
