[GitCMS](https://gitcms.dev) is a Git-based CMS positioned around human and AI-assisted website editing. Like other Git-based CMS tools, it keeps content in a repository and uses commits as the publishing mechanism. Its differentiator is an emphasis on reviewable workflows for agent-generated changes. | Area | GitCMS focus | Trade-off |
| :--- | :--- | :--- |

| **Editing workflow** | Visual/editorial layer over repository files [VERIFY] | Younger ecosystem than established CMS options |
| **AI workflows** | Designed for human review of agent changes [VERIFY] | May be unnecessary for solo writers |
| **Pricing/licensing** | Free tier plus paid plans [VERIFY] | Not the same as fully open-source self-hosted tools |

## When to consider GitCMS

GitCMS is worth evaluating if AI agents or automated tools regularly propose changes to your site and you need an editorial review layer before publishing. For teams that only need simple manual editing of Markdown in GitHub, lighter tools such as Pages CMS or Decap CMS may be sufficient. ## Comparison context

Choose GitCMS when AI-assisted governance is part of your workflow. Choose a simpler Git-based CMS when you only need straightforward content editing and Git commits.
