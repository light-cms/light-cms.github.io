LightCMS и Содержательные различные варианты использования. LightCMS is designed for Git based static site publishing, where content lives in a repository and is deployed as static files. Содержимое - это корпоративный бесконечный CMS который предоставляет структурированный контент через API для веб-сайтов, приложений и других каналов.

## Сравнение

| Область               | LightCMS                                                           | Содержимое                                        |
| :-------------------- | :----------------------------------------------------------------- | :------------------------------------------------ |
| Основная модель       | Git based CMS for static sites                                     | Бесконечный CMS SaaS                              |
| Хранилище содержимого | Репозиторий Markdown/files                                         | Управляемая поставщиком платформа для контента    |
| Доставка              | Статический вывод сборки                                           | API контента                                      |
| Лучший подбор         | Блоги, документация, маркетинговые сайты                           | Многоканальные операции по содержанию предприятия |
| Управление            | Git рабочие процессы, PRs, разрешения репозитория                  | Роли, рабочие процессы, окружения, локализация    |
| Себестоимость модели  | Стоимость продукта/хостинга варьируется в зависимости от стоимости | Цены на подписку/использование/сидение            |

## Выбор между ними

Контент имеет смысл, когда один и тот же контент должен перемещаться по нескольким каналам и вам нужно управление предприятиями, потоки работ или управляемая платформа с API и SLAs.

LightCMS имеет больше смысла, когда ваш основной вывод является статическим сайтом и вы хотите, чтобы контент жил в Git. У вас есть простая настройка публикации, но вы не получите один и тот же уровень операций с контентом предприятия.

Он идет к масштабу и форме. Если вы работаете с контентом в командах, продуктах и каналах, контент может оправдать его стоимость и блокировку поставщика. Если вы публикуете сайт, владеющий репозиторием Markdown обычно спокойнее и дешевле для работы. См. [LightCMS против Sanity](/comparison/lightcms-vs-sanity) или [Headless CMS Объяснить](/blog/headless-cms-explained/).
