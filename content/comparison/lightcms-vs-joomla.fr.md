LightCMS et Joomla représentent différents modèles CMS. LightCMS supports Git based static site publishing with Markdown content. Joomla est un CMS PHP traditionnel qui stocke le contenu dans une base de données et rend les pages via une application côté serveur.

## Comparaison

| Zone de stockage    | LightCMS                                 | Joomla                                          |
| :------------------ | :--------------------------------------- | :---------------------------------------------- |
| Architecture        | Fichiers Git + build statique            | Application PHP + base de données               |
| Équivalent en cours | Fichiers statiques précompilés           | Rendu côté serveur                              |
| Extensibilité       | Outils de construction/services externes | Extensions/composants/modules                   |
| Entretien           | Dépôt, contenu, CI/CD                    | Core, extensions, PHP, hébergement              |
| Meilleure forme     | Sites statiques axés sur le contenu      | Sites dynamiques nécessitant des extensions CMS |

## Choix entre eux

Joomla a un sens lorsque vous avez besoin d'un CMS traditionnel avec des fonctionnalités côté serveur, des extensions et des flux de travail d'administration familiers.

LightCMS a un sens lorsque le projet est principalement une publication. Si vous voulez une livraison statique, une complexité d'exécution plus faible et un contenu stocké dans Git, la configuration plus légère est plus facile à gérer.

Joomla peut gérer les besoins dynamiques de CMS, mais vous prenez en charge le travail de maintenance et de sécurité. LightCMS continue à publier simple, mais il ne remplacera pas un CMS dynamique lourd.
