WordPress и LightCMS могут опубликовать веб-сайт, но они приходят с очень различным багажом. WordPress это PHP приложение с базой, темы, плагины и панели администратора. LightCMS является
редактором на основе Git для статических сайтов: содержимое живет как Markdown файлы, а ваш трубопроводник публикует статический HTML.

Если вам нужен веб-сайт, который ведет себя как приложение, WordPress по-прежнему имеет реальные преимущества. Если вам нужна публикация, которая быстро загружается и остается простой в обслуживании, то статический маршрут проще жить.

## Как они отличаются

|                       | LightCMS                                 | WordPress                                                                      |
| --------------------- | ---------------------------------------- | ------------------------------------------------------------------------------ |
| Хранилище содержимого | Markdown файлы в Git                     | База данных MySQL                                                              |
| Рендеринг             | Предостроенный статический HTML          | PHP отображает страницы во время выполнения                                    |
| Рунтайм               | На реальном сайте нет CMS                | Веб-сервер, PHP, база данных                                                   |
| Расширенность         | Создание инструментов и внешних сервисов | Плагины и темы                                                                 |
| Versioning            | Git history                              | Ревизы/плагины WordPress                                                       |
| Лучше для             | Блоги, документация, маркетинговые сайты | Сайты, которым нужны плагины, динамические функции, процессы администрирования |

## Когда WordPress имеет больше смысла

WordPress имеет смысл, когда вам нужна его экосистема. Если вы хотите, чтобы плагины для членства, электронная почта, формы, инструменты поисковой оптимизации, или сложные редакционные рабочие потоки, WordPress может сэкономить много времени. У него также есть огромный пул найма и знакомый админ-интерфейс.

## Когда LightCMS имеет больше смысла

LightCMS имеет смысл, когда ваш сайт в основном контент. Статический сайт не нуждается в базе данных или PHP по каждому запросу, который удаляет кусочек работы по обслуживанию и безопасности. Ваш контент остается в Git, поэтому история, обзор и откат являются частью нормального рабочего процесса.

Опыт работы в области письменного перевода также прост. Авторы редактируют в браузере; разработчики сохраняют трубопровод сборки. Никто не должен входить в рабочий администратор CMS, чтобы исправить опечатку.

## Выбор между ними

Выберите WordPress если вам нужны динамические функции и большая экосистема плагинов. Выберите LightCMS если вы хотите быстрое, низкое техническое обслуживание публикации, и вам удобна статическая модель сайта. WordPress дает вам гибкость через плагины; LightCMS дает вам простоту через файлы и сборки.

Если вы сегодня на WordPress попробуйте небольшой тест миграции: экспортируйте несколько сообщений в Markdown и посмотрите, насколько сильно ваш сайт действительно по сравнению с плагином. Содержание обычно перемещается легко. Поведение плагина в этом месте реальные решения. См.
