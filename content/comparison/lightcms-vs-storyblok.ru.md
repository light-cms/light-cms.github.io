Storyblok и LightCMS называют себя визуальными редакторами, но они визуально по-разному. Storyblok позволяет строить страницы из блоков и видеть макет при редактировании. LightCMS предоставляет вам чистый редактор документов для написания статей, которые в конечном итоге становятся Markdown в вашем Git-репозитории.

Правильный выбор зависит от того, что вы делаете. Целевая страница, созданная из повторно используемых компонентов, нуждается в инструменте, отличном от 1500 слов, блоге с примерами кода и скриншотами.

## Как они работают

Storyblok - это хостинг без заголовков CMS. Контент моделируется как блоки, отредактируется в предпросмотре и поставляется через API. Ваш интерфейс извлекает содержимое и отображает его.

LightCMS is a Git based writing workspace. Содержимое хранится в Markdown файлах с фронт-телом в вашем репозитории. Вы пишете в редакторе документов, зафиксируйте изменения, и ваш статический генератор сайта строит сайт.

|                       | LightCMS                               | Storyblok                                            |
| --------------------- | -------------------------------------- | ---------------------------------------------------- |
| Хранилище содержимого | Файлы в Git-репозитории                | Размещенный CMS                                      |
| Доставка              | Статическая сборка в CDN               | Content API                                          |
| Редактировать стиль   | Первая запись документа                | Визуальное редактирование страницы на основе блоков  |
| Лучше для             | Статьи, документация, список изменений | Посадочные страницы, сайты, управляемые компонентами |
| Предпросмотр          | После создания/просмотра сайта         | Просмотр видео в реальном времени                    |
| Цены                  | Самохостинг, без лицензионного сбора   | Плановые SaaS                                        |

## Когда Storyblok делает больше смысла

Storyblok светится, когда страница сама по себе продукт. Если маркетологам нужно перемещаться по герою, сетке, отзывам или CTA, не спрашивая разработчика, визуальный редактор с блоком имеет смысл. Предварительный просмотр помогает при создании макета как можно больше, чем копия.

## Когда LightCMS имеет больше смысла

LightCMS светится, когда написание является продуктом. Длинные статьи в блочном редакторе могут почувствовать заклинание. В редакторе документов вы просто пиште: заголовки, списки, таблицы, изображения, код, все в потоке. Результатом является простой Markdown в Git, который позволяет легко публиковать ваш контент в виде статических файлов.

## Выбор между ними

Выберите Storyblok, если ваша команда должна создавать и перераспределять страницы визуально. Выберите LightCMS если ваша команда в основном публикует статьи и документацию и хочет спокойно писать опыт.

Если вы находитесь на ограждении, посмотрите на последние десять опубликованных страниц. Если большинство из них структурированы маркетинговыми страницами, то Storyblok подходят. Если большинство статей или документов, то LightCMS скорее всего будет выглядеть лучше.
