LightCMS и Ghost поддерживают публикацию, но они собраны для различных результатов. LightCMS is a Git based workflow for static site content. Ghost - это издательская платформа со встроенным членством, подпиской и новостными возможностями.

## Сравнение

| Область           | LightCMS                                         | Призрак                                       |
| :---------------- | :----------------------------------------------- | :-------------------------------------------- |
| Архитектура       | Git based content + static build                 | Приложение + платформа базы данных            |
| Основная сила     | Рабочий процесс по статическому контенту сайта   | Публикация бизнес-функций                     |
| Участники/платежи | Не Ядро CMS                                      | Нативные членства/подписки                    |
| Рассылка          | Зависит от внешнего рабочего процесса/интеграции | Функции Родной рассылки                       |
| Хостинг           | Статический хост/DN                              | Призрачный хостинг или самохостинг приложение |

## Выбор между ними

Ghost - это сильный выбор, когда ваша публикация также ваш бизнес. Если членство, платная подписка и родные бюллетени играют центральную роль в том, что вы делаете, то в Ghost построены эти части.

LightCMS лучше подходит, когда ваш сайт в основном содержимое. Вы получаете Markdown в Git, статическую доставку и простую настройку. Вы можете использовать внешние сервисы для рассылки или членства, но вы будете делать это интеграция самостоятельно.

Итак, вопрос довольно прост: вы ли ведете публикацию или аудиторию? См. [LightCMS против WordPress](/comparison/lightcms-vs-wordpress) и [Best CMS for Static Sites](/blog/best-cms-for-static-sites/).
