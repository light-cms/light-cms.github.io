LightCMS und Ghost unterstützen beide Publishing, aber sie sind für verschiedene Ergebnisse gebaut. LightCMS is a Git based workflow for static site content. Ghost ist eine Publishing-Plattform mit integrierten Mitgliedschafts-, Abonnement- und Newsletter-Fähigkeiten.

## Vergleich

| Fläche                     | LightCMS                                   | Geist                                   |
| :------------------------- | :----------------------------------------- | :-------------------------------------- |
| Architektur                | Git based content + static build           | Anwendung + Datenbankplattform          |
| Primäre Stärke             | Statischer Seiteninhalt-Workflow           | Publishing von Geschäftsfunktionen      |
| Mitgliedschaften/Zahlungen | Kein Kern-CMS-Feature                      | Native Mitgliedschaften/Abonnements     |
| Newsletter                 | Abhängig von externer Workflow/Integration | Native Newsletter-Funktionen            |
| Hosting                    | Statischer Host/CDN                        | Ghost Hosting oder selbst gehostete App |

## Wählen Sie zwischen ihnen

Ghost ist eine starke Wahl, wenn Ihre Veröffentlichung ist auch Ihr Geschäft. Wenn Mitgliedschaften, bezahlte Abonnements und einheimischer Newsletter im Mittelpunkt des Geschehens stehen, hat Ghost diese Stücke eingebaut.

LightCMS ist eine bessere Passform, wenn Ihre Website hauptsächlich Inhalt hat. Sie erhalten Markdown in Git, statische Lieferung und eine einfachere Einrichtung. Sie können externe Dienste für Newsletter oder Mitgliedschaften einbinden, aber Sie tun diese Integration selbst.

Die Frage ist also ziemlich einfach: Führen Sie eine Publikation oder ein Publikumsgeschäft? Siehe [LightCMS vs WordPress](/comparison/lightcms-vs-wordpress) und [Best CMS for Static Sites](/blog/best-cms-for-static-sites/).
