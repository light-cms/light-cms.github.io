LightCMS и Drupal обслуживают различные масштабы управления контентом. LightCMS - это рабочий процесс на основе Git для статического содержания сайта, обычно Markdown в репозитории. Drupal - это PHP-фреймворк, предназначенный для сложных моделей контента, разрешений и расширений.

## Сравнение

| Область                  | LightCMS                                 | Крупал                                              |
| :----------------------- | :--------------------------------------- | :-------------------------------------------------- |
| Архитектура              | Файлы Git + статическая сборка сайта     | PHP приложение + база данных                        |
| Модель контента          | Документ/передний план                   | Сущности, поля, таксономии, модули                  |
| Управление               | Git/repo рабочие процессы                | Роли, рабочие процессы, разрешения                  |
| Техническое обслуживание | Контент и сборка трубопровода            | Ядро, модуль, безопасность, обслуживание хостинга   |
| Лучший подбор            | Блоги, документация, маркетинговые сайты | Сложные организационные сайты или сайты предприятий |

## Выбор между ними

Drupal имеет смысл, когда вам нужны сложные модели контента, тонкие разрешения, многоязычные рабочие потоки или поведение CMS, которые начинают выглядеть как приложение. Он создан для организаций с разработчиками и поддержкой ops.

LightCMS имеет смысл, когда сайт в основном является публикацией. Если вы хотите поставлять статическое содержимое, репо, и проще писать рабочий процесс, вам не нужен вес Drupal.

Для небольшого издательского сайта Drupal может быть много инфраструктуры для работы. Для большой организации со сложными требованиями LightCMS может чувствовать себя слишком ограниченным. См. [LightCMS против WordPress](/comparison/lightcms-vs-wordpress) и [Статик против динамических сайтов](/blog/static-vs-dynamic/).
