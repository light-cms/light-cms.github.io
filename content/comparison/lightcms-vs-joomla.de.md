LightCMS und Joomla repräsentieren verschiedene CMS-Modelle. LightCMS supports Git based static site publishing with Markdown content. Joomla ist ein traditionelles PHP-CMS, das Inhalte in einer Datenbank speichert und Seiten über eine serverseitige Anwendung darstellt.

## Vergleich

| Fläche          | LightCMS                            | Joomla                                 |
| :-------------- | :---------------------------------- | :------------------------------------- |
| Architektur     | Git Dateien + statische Erstellung  | PHP-Anwendung + Datenbank              |
| Rendern         | Vorgebaute statische Dateien        | Serverseitige Darstellung              |
| Erweiterbarkeit | Erstelle Werkzeuge/externe Dienste  | Erweiterungen/Komponenten/Module       |
| Wartung         | Repo, Inhalt, CI/CD                 | Kern, Erweiterungen, PHP, Hosting      |
| Beste Passung   | Inhaltsfokussierte statische Seiten | Dynamische Sites mit CMS-Erweiterungen |

## Wählen Sie zwischen ihnen

Joomla macht Sinn, wenn Sie ein traditionelles CMS mit serverseitigen Funktionen, Erweiterungen und vertrauten Admin-Workflows benötigen.

LightCMS macht Sinn, wenn das Projekt meist eine Publikation ist. Wenn Sie statische Auslieferung, geringere Laufzeitkomplexität und in Git gespeicherte Inhalte wollen, ist das Setup leichter zu verwalten.

Joomla kann dynamische CMS-Anforderungen bewältigen, aber Sie übernehmen Wartungs- und Sicherheitsarbeiten. LightCMS veröffentlicht weiterhin einfach, ersetzt aber kein erweiterungsschweres dynamisches CMS.
