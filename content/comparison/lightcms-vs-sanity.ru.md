Санити и LightCMS помогают публиковать контент, но они начинаются с разных мест. Sanity - платформа размещенного контента: ваш контент живет в Sanity's Content Lake, вы моделируете его по схемам, и ваш фронтенд получает его через API. LightCMS is a Git based editor: your content lives as Markdown files in your repository, and your static site generator builds HTML from those files.

Если вы создаете блог, сайт с документацией или маркетинговый сайт, реальный вопрос прост: вам нужен API контента, или вам нужно хорошее место для написания и публикации?

## Как изменяется модель хранения

С Sanity данные структурированы в службу хостинга. Вы запрашиваете это с помощью GROQ, и изменения могут быть доступны сразу через API. Это имеет смысл, когда один и тот же контент питается веб-сайтом, приложением и другими клиентами.

В LightCMS содержимое является файлом в вашем репозитории. Вы редактируете его, зафиксируйте и ваш конвейер публикует его. Нет API содержимого рабочего времени для продолжения работы. Это имеет смысл, когда выход является статическим сайтом, и вы хотите, чтобы история контента жила в Git.

|                                   | LightCMS                               | Санити                                   |
| --------------------------------- | -------------------------------------- | ---------------------------------------- |
| Хранилище содержимого             | Markdown файлы в вашем Git-репозитории | Размещенное содержимое озеро             |
| Доставка                          | Статическая сборка в CDN               | API в момент запроса                     |
| Content modeling                  | Передние поля                          | Пользовательские схемы в коде            |
| Сотрудничество в реальном времени | Рабочий процесс по обзору Git          | Сотрудничество студии в реальном времени |
| Цены                              | Самохостинг, без лицензионного сбора   | Использование/планы базирования          |
| Портабельность                    | Клонировать репозиторий                | Экспортировать и конвертировать          |

## Когда Санити имеет больше смысла

Санити заработает, когда контент больше страниц. Если один и тот же контент должен появиться на сайте, приложение и в другом месте, структурированная модель и API компании Sanity. Он также обрабатывает пользовательские схемы, ссылки и взаимодействие в реальном времени в редакторе.

## Когда LightCMS имеет больше смысла

LightCMS подходит, когда в основном публикуете документы на статическом сайте. Вы пишете в редакторе, содержимое живет в вашем репозитории, и сайт встраивается в статические файлы. По каждому запросу нет API контента и ни одного хранилища контента не работает в центре.

Для писателей эта разница ощущается каждый день. LightCMS настроена на разработку и публикацию статей. Sanity Studio — мощная программа, но она построена вокруг контента моделирования.

## Выбор между ними

Если ваш контент должен вести себя как данные о продукте (структура, запрос, повторное использование и обновление в режиме реального времени), Sanity является более сильным выбором. Если большинство ваших работ - статьи и страницы, то LightCMS проще жить: файлы в Git, статические поставки, меньше подвижных частей.

Хороший способ решить, это взглянуть на ваше содержимое. If it’s mostly long-form posts with front matter, start with the Git based path. Если вы продолжаете работать в отношениях и работаете по запросам или нескольким фронтендам, то это когда бесголовная платформа, подобная Sanity, начинает зарабатывать свою сложность.
