LightCMS и Joomla представляют различные модели CMS . LightCMS supports Git based static site publishing with Markdown content. Joomla - это традиционный PHP-CMS, который хранит содержимое в базе данных и отображает страницы через серверное приложение.

## Сравнение

| Область                  | LightCMS                                         | Joomla                                       |
| :----------------------- | :----------------------------------------------- | :------------------------------------------- |
| Архитектура              | Файлы Git + статическая сборка                   | PHP приложение + база данных                 |
| Рендеринг                | Предварительно созданные статические файлы       | Серверный рендеринг                          |
| Расширенность            | Создать инструменты/внешние сервисы              | Расширения/компоненты/модули                 |
| Техническое обслуживание | Повтор, содержимое, CI/CD                        | Ядро, расширения, PHP, хостинг               |
| Лучший подбор            | Статические сайты, ориентированные на содержание | Динамические сайты, требующие расширения CMS |

## Выбор между ними

Joomla имеет смысл, когда вам нужны традиционные CMS с функциями, расширениями и знакомыми администраторами.

LightCMS имеет смысл, когда проект в основном является публикацией. Если вы хотите статическую доставку, пониженную сложность выполнения и контент хранится в Git, то легче управлять более легкой настройкой.

Joomla может справиться с динамическими потребностями CMS, но вы берете на себя работу по обслуживанию и безопасности. LightCMS сохраняет публикацию простым, но не заменяет динамическую CMS.
