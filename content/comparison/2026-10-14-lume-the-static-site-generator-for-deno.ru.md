[Lume](https://lume.land) — это статический генератор сайта, построенный для экосистемы Deno. Он генерирует статический HTML из файлов содержимого, шаблонов и данных, что делает его подходящим для блогов, документация и другие контентные сайты, которые могут быть развернуты на CDN.

## Что дает урок

| Область             | Что ожидать                                                | Сделка                                            |
| :------------------ | :--------------------------------------------------------- | :------------------------------------------------ |
| Рунтайм             | Выполняется на Deno                                        | Мелкие экосистемы, чем генераторы на основе узлов |
| Форматы содержимого | Markdown, файлы данных, шаблоны; плагины расширяют форматы | Выбор плагина/конфигурации добавляет сложность    |
| Шаблоны             | Поддержка нескольких движков шаблонов и JSX через плагины  | Команда должна выбирать конвенции рано            |
| Вывод               | Статические файлы для CDN/статического хостинга            | Динамические функции требуют отдельных сервисов   |

## Когда выстрел хороший подбор

Lume является разумным выбором, если ваша команда уже использует Deno и хочет статический генератор сайта с гибким шаблоном и плагином трубопровода. Это менее убедительно, если ваша команда зависит от экосистемы Node/npm, существующих рабочих потоков Eleventy/Hugo/Astro, или от большого тематического рынка.

## Редактирование юма и контента

Дает возможность генерации сайта, а не редактирования контента. If writers need a browser-based interface, pair Lume with a Git based CMS that commits Markdown or compatible content files to the repository.
