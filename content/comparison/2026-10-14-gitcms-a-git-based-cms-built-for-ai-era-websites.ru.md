[GitCMS](https://gitcms.dev) — это CMS основанный на Git, расположенный вокруг человека и помогающий AI редактирование веб-сайтов. Как и другие инструменты CMS на основе Git, контент хранится в хранилище и использует коммиты в качестве механизма публикации. Его дифференциатор делает акцент на поддающихся проверке рабочих потоках для происходящих в Агентстве изменений.

## Где подходят GitCMS

| Область                          | GitCMS фокус                                            | Сделка с                                                        |
| :------------------------------- | :------------------------------------------------------ | :-------------------------------------------------------------- |
| Хранилище содержимого            | Git репозиторий как источник истины                     | Все еще требуется настройка Git/CI/CD                           |
| Редактирование рабочего процесса | Визуальный/редактор над файлами репозитория             | Младшая экосистема по сравнению с установленными вариантами CMS |
| Рабочие процессы ИИ              | Предназначена для изучения изменений агентов в человеке | Может быть ненужным для сольных писателей                       |
| Цена/лицензирование              | Бесплатный уровень плюс платные планы                   | Не то же самое, что и инструменты с открытым исходным кодом     |

## Когда рассматривать GitCMS

GitCMS стоит оценить, если AI агенты или автоматизированные инструменты регулярно предлагают изменения на вашем сайте, и вам нужен уровень редакционного обзора перед публикацией. Для команд, которым требуется только ручная редактирование Markdown в GitHub, более легкие инструменты, такие как Pages CMS или Decap CMS может быть достаточным.

## Контекст сравнения

Выберите GitCMS когда управление с помощью AI является частью вашего рабочего процесса. Выберите более простой CMS основанный на Git, когда вам требуется только простое редактирование контента и Git коммиты. Для более широких сравнений см. [Платформы основанные на Git] (/comparison/top-git-cms) и [Pages Alternatives] (/comparison/pagescms).
