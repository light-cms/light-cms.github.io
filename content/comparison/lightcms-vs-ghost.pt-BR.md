LightCMS e Ghost ambos suportam publicação, mas são construídos para resultados diferentes. LightCMS é um fluxo de trabalho baseado no Git para conteúdo estático do site. O Ghost é uma plataforma de publicação com recursos embutidos de assinatura, assinatura e newsletter.

## Comparação

| área               | CMS                                           | Fantasma                                         |
| :----------------- | :-------------------------------------------- | :----------------------------------------------- |
| Arquitetura        | Conteúdo baseado no Git + compilação estática | Aplicativo + plataforma de banco de dados        |
| Força principal    | Workflow de conteúdo estático do site         | Publicando recursos comerciais                   |
| Membros/Pagamentos | Não é um recurso núcleo CMS                   | Assinaturas/Assinaturas nativas                  |
| Notícias           | Depende de workflow/integração externa        | Recursos da newsletter nativa                    |
| Hospedagem         | Host/CDN estático                             | Hospedagem fantasma ou aplicativo auto-hospedado |

## Escolhendo entre eles

O Ghost é uma escolha forte quando sua publicação também é da sua conta. Se as adesões, assinaturas pagas e boletins nativos são centrais para o que você está fazendo, o Ghost tem essas peças feitas.

LightCMS é um formato melhor quando seu site é o principal conteúdo. Você começa o Markdown no Git, a entrega estática e uma configuração mais simples. Você pode navegar nos serviços externos para boletins informativos ou adesões, mas você mesmo fará essa integração.
