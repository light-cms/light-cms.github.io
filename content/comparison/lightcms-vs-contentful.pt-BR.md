Leve CMS e destinos de conteúdo diferentes de utilização. LightCMS is designed for Git based static site publishing, where content lives in a repository and is deployed as static files. O conteúdo é um CMS corporativo sem cabeça que oferece conteúdo estruturado por meio de APIs para sites, apps e outros canais.

## Comparação

| área                      | CMS                                             | Conteúdo                                            |
| :------------------------ | :---------------------------------------------- | :-------------------------------------------------- |
| Modelo primário           | Git based CMS for static sites                  | SaaS CMS sem cabeça                                 |
| Armazenamento de conteúdo | Marcação/arquivos do repositório                | Plataforma de conteúdo gerenciado pelo fornecedor   |
| Entrega                   | Saída de compilação estática                    | APIs de Conteúdo                                    |
| Melhor ajuste             | Blogs, documentos, sites de marketing           | Operações de conteúdo empresarial de vários canais  |
| Governança                | Fluxos de trabalho Git, PRs, permissões de repo | Funções, fluxos de trabalho, ambientes, localização |
| Modelo de custo           | Custos de produto/auto-hospedagem variam        | Assinatura/uso/preços baseados no assento           |

## Escolhendo entre eles

O conteúdo faz sentido quando o mesmo conteúdo tem que viajar através de vários canais e você precisa da governança da empresa. workflows, ou uma plataforma gerenciada com APIs e SLAs.

LightCMS faz mais sentido quando sua saída principal é um site estático e você quer conteúdo vivendo no Git. Você obtém uma configuração de publicação mais simples, mas não recebe a mesma camada de operações de conteúdo empresarial.

Desce à escala e à forma. Se você estiver executando o conteúdo em equipes, produtos e canais, Conteúdo pode justificar o seu custo e o bloqueio do fornecedor. Se você está publicando um site, o Markdown é geralmente mais calmo e barato de operar.
