LightCMS和Ghost 都支持出版，但它们是为不同的结果而构建的。 LightCMS是基于 Git 的静态站点内容工作流。 Ghost 是一个发布平台，拥有内置的会员资格，订阅和通讯能力。

## 比较

| 区域    | LightCMS          | 幽灵：          |
| :---- | :---------------- | :----------- |
| 结构    | 基于 Git 的内容 + 静态版本 | 应用程序 + 数据库平台 |
| 主要强度  | 静态站点内容工作流         | 发布业务功能       |
| 成员/付款 | 不是核心CMS功能         | 本机成员/订阅      |
| 新闻通讯  | 依赖外部工作流/集成        | 本机通讯功能       |
| 主机    | 静态主机/CDN          | 主机或自托管应用     |

## 二者之间的选择

当你的出版物也是你的业务时，幽灵是一个很强的选择。如果成员资格、付费订阅和本机通讯是你正在做的事情的核心，Ghost 就会把这些内容嵌入其中。

当您的站点主要是内容时，LightCMS是更好的。你在Git里得到Markdown ，静态送货和一个更简单的设置。您可以为新闻通讯或会员而支持外部服务，但您将自己做这种集成。

所以问题很简单：您是在经营一个出版物还是在经营一个观众业务？ See [LightCMS vs WordPress](/comparison/lightcms-vs-wordpress) and [Best CMS for Static Sites](/blog/best-cms-for-static-sites/).
