Webflow и LightCMS решают различные проблемы. Webflow — визуальный конструктор сайтов с хостингом и встроенным CMS . LightCMS - это редактор контента для сайтов, код которых уже живет в Git репозитории. Если у вас нет разработчиков, то Webflow может получить вам долгий путь. Если у вас уже есть база кода, то LightCMS помещается в этот рабочий процесс вместо его замены.

## Различные задания

Webflow предоставляет визуальный холст для проектирования страниц, управления коллекциями CMS и публикации в инфраструктуре Webflow. Дизайн, содержание и хостинг тесно связаны.

LightCMS предполагает, что интерфейс уже существует. Разработчики владеют шаблонами и создают трубопровод; писатели используют LightCMS для редактирования Markdown и передней части, а затем фиксируют изменения в Git.

|                       | LightCMS                         | Веб-поток                                         |
| --------------------- | -------------------------------- | ------------------------------------------------- |
| Дизайн                | Ваш код и шаблоны                | Визуальный дизайн холста                          |
| Хранилище содержимого | Markdown в Git                   | Размещенные коллекции CMS                         |
| Публикация            | Ваш CI/CD и хост                 | Хост/публикация веб-потока                        |
| Редактирование        | Редактор документов для Markdown | Поля CMS привязаны к дизайнам                     |
| Управление версиями   | Git history                      | Версия платформы, не Git                          |
| Лучше для             | Developer owned static sites     | Желающие команды дизайн + CMS в одном инструменте |

## Когда Webflow имеет больше смысла

Webflow является сильным выбором, когда вы хотите создать, построить и опубликовать сайт без управления хранилищем кода и трубопровода CI. Маркетинговые команды могут быстро перемещаться, предварительно просматривать изменения и публиковать их без ожидания разработчика.

## Когда LightCMS имеет больше смысла

LightCMS - лучший выбор, когда ваш сайт уже код. Вы сохраняете контроль над шаблонами, фреймворком, хостингом и историей Git. Авторы получают чистый редактор, но сам сайт остается в вашем репозитории. Это также облегчает перемещение хостов или генераторов позже, потому что ваш контент уже простой Markdown.

## Выбор между ними

Выберите Webflow если вы хотите, чтобы одна платформа работала с дизайном, CMS и хостингом. Выберите LightCMS если вы хотите иметь код и рассматривать его как файлы в Git. Webflow сокращает техническую настройку; LightCMS сохраняет за собой техническую собственность.

Простой тест: если дизайнер нуждается в изменении макета завтра, Webflow удобен. Если разработчик владеет макет и писатель должен публиковать только содержание, LightCMS является более чистой формой.
