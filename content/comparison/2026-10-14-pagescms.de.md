Pages CMS ist ein Git basiertes CMS mit Schwerpunkt auf einfache formbasierte Bearbeitung über Repository-Inhalte. Teams suchen nach Alternativen, wenn sie reichere Schreibschnittstellen benötigen, visuelle Bearbeitung, stärkere Schemas, Unterstützung für mehrere Anbieter Git oder verwaltetes Hosting.

## Alternativen auf einen Blick

| Alternativ   | Beste Passung                                               | Key Trade-off                                               |
| :----------- | :---------------------------------------------------------- | :---------------------------------------------------------- |
| LightCMS     | Visuelle Markdown-Bearbeitung für statische Seiten          | Aktuelles Featureset und Hosting-Optionen überprüfen        |
| Decap CMS    | Git basiertes CMS mit config-driven Sammlungen eingerichtet | UI/config Workflow kann sich für Autoren als datiert fühlen |
| TinaCMS      | Visuelle oder strukturierte Bearbeitung mit Git-Sync        | Erfordert Schema/Setup-Entscheidungen                       |
| Keystatische | Entwickler-orientierte lokal-erste Inhaltsschemas           | Weniger schreiber-fokussiert                                |
| Sveltia CMS  | Leichte browserbasierte CMS UI                              | Jüngeres Projekt; Überprüfung der Laufzeit                  |
| Cloudkanone  | Verwaltete visuelle Bearbeitung für Teams/Agenturen         | Kommerzielle Preise                                         |

## Auswahlkriterien

Beim Vergleich von Seiten CMS-Alternativen evaluieren:

- Erfahrung bearbeiten: Formularfelder, WYSIWYG oder On-Page Editing.
- Unterstützung für Git-Provider: Nur GitHub oder auch GitLab/Bitbucket.
- Inhaltsmodell: Front-Materie/-Formulare, eingegebene Schemas oder strukturierte Blöcke.
- Medienbehandlung: Uploads, Asset-Pfade und externer Speicher.
- Operationsmodell: Hosted SaaS, selbstgehostete App oder statische Admin-UI.

Für Teams, die bereits Markdown in Git verwenden, ist Migration oft möglich, ohne Inhalte zu verschieben. Das Hauptwerk sind die Kartierungsfelder, Medienpfade und Redaktionsworkflow.
