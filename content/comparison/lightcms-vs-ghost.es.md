Tanto LightCMS como Ghost apoyan la publicación, pero están construidos para diferentes resultados. LightCMS is a Git based workflow for static site content. Ghost es una plataforma de publicación con las capacidades incorporadas de membresía, suscripción y boletín.

## Comparación

| Área                | LightCMS                                         | Fantasma                                        |
| :------------------ | :----------------------------------------------- | :---------------------------------------------- |
| Arquitectura        | Git based content + static build                 | Aplicación + plataforma de base de datos        |
| Intensidad primaria | Flujo de trabajo de contenido del sitio estático | Publicando características de negocio           |
| Membresías/pagos    | No es una característica CMS del núcleo          | Membresías/suscripciones nativas                |
| Boletines           | Depende del workflow/integración externa         | Características nativas del boletín de noticias |
| Alojamiento         | Host/CDN estático                                | Hospedaje fantasma o aplicación autoalojada     |

## Eligiendo entre ellos

El fantasma es una buena opción cuando su publicación es también su negocio. Si las membresías, las suscripciones pagadas y los boletines nativos son fundamentales para lo que estás haciendo, Ghost tiene las piezas incorporadas.

LightCMS es un mejor ajuste cuando su sitio es principalmente de contenido. Obtienes Markdown en Git, entrega estática y una configuración más sencilla. Usted puede incluir servicios externos para boletines de noticias o membresías, pero usted mismo estará haciendo esa integración.

Así que la pregunta es bastante simple: ¿está corriendo una publicación o un negocio de audiencia? Ver [LightCMS vs WordPress](/comparison/lightcms-vs-wordpress) y [Mejor CMS para sitios estáticos](/blog/best-cms-for-static-sites/).
