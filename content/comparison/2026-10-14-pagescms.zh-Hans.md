Pages CMS is a Git based CMS focused on simple form-based editing over repository content. 当团队需要更丰富的写作界面、视觉编辑、更强大的架构、多提供商Git支持或管理托管时，它们会寻找替代品。

## 1. 一眼中的替代物

| 备选办法        | 最合适的                                                     | 密钥交易                          |
| :---------- | :------------------------------------------------------- | :---------------------------- |
| LightCMS    | 静态站点的视觉Markdown编辑                                        | 验证当前功能集和托管选项                  |
| 去除CMS       | Established Git based CMS with config-driven collections | UI/config Workflow 可以为作者觉得过时了 |
| TinaCMS     | 使用 Git 同步进行视觉或结构编辑                                       | 需要方案/设置决定                     |
| 静态键         | 面向开发者的本地第一内容方案                                           | 从盒子中较少专注于撰写者                  |
| Sveltia CMS | 基于浏览器的轻量CMS界面                                            | 较小的项目；核实到期时间                  |
| 云塔          | 管理团队/机构的视觉编辑                                             | 商业价格                          |

## 甄选标准

比较页面CMS替代时，评估：

- 编辑经验：表单字段，WYSIWYG，或页面编辑。
- Git 提供商支持: GitHub 只支持或同时支持 GitLab/Bitbucket
- 内容模型：前面的事项/表格、类型方案或结构化块。
- 媒体处理：上传、资产路径和外部存储。
- 操作模式：托管SaAS、自托管应用或静态管理UI。

对于已经在Git中使用Markdown 的团队来说，迁移往往是可能的，没有移动内容。主要工作是绘制田地、媒体路径和编辑工作流程。
