[Pages CMS](/comparison/pagescms/) earned its reputation as the simplest free GitHub CMS: form based editing, MIT licensed, hosted or self hosted.

---

## 为什么超越页面CMS？

页面CMS做得很好：它给任何人在 GitHub 仓库提供了一个干净的表单。团队最终需要更多：真正的 WYSIWYG 写作经验、视觉编辑、更强大的方案或建立在新闻通讯等发行功能中。下面每个备选方案都有不同的交易。

## 1. LightCMS

[LightCMS](/getting-started/) 替换为完整的 Tiptap WYSIWYG 编辑器(格式化文本，数学，) 代码高亮、表格和拖放媒体，同时仍然向GitHub 提交普通Markdown和前体。它可以是自己托管和Apache 2。 已许可，它捆绑了页面CMS留下的内容：AI 起草副本， 用 [wit.ai](wit.ai) 语音来语音或自然语言了解 和 [newsletters](/blog/newsletter-email-automation/) 通过 Newsy, 没有电子邮件服务。

**如果** 作者觉得他们正在使用现代编辑器，而不是填写表单，请选择它。

> [LightCMS](https://lightcms.me计划将来支持 bitbucket, gitlab 和 forgejo。

## 2. 去除CMS

类别的老兵(原为 Netlify CMS)：通过 `config.yml` 、 支持 GitHub 、 GitLab和 Bitbucket 配置的可部署React 管理应用程序。生态系统不匹配；接口已经过时。 Full details in [Decap CMS explained](/comparison/netlifycms/).

\*\*如果你需要多供应商支持或正在运行它，请选择它。

## 3. TinaCMS

在页面编辑上嵌入：点击渲染页面上的任何元素并进行编辑。先进行Markdown ，为个人提供免费等级。

**选择它，如果** 直接编辑页面会为您的工作流程单独拍摄一个仪表板。

## 4. 静态键

本地第一个内容与React表单和优秀的模式验证，内容以文件形式存在，并且在你想要时同步到 GitHub

\*\*如果您是Next.js/Astro世界的开发者，请选择它。您首先需要输入内容。

## 5. Sveltia CMS

一个静态文件为您提供了一个免费的基于浏览器的管理员通过 GitHub API，这是可用的最简单的替代方法。

\*\*如果你想要几乎零的基础设施，请选择它。

## 6. 云塔

一个管理好的、商业性的 Git CMS，拥有强大的视觉编辑和工作流程工具，可以选择许多机构管理多个客户网站。

\*\*如果你想让一个供应商为你操作整个编辑层，请选择它。

## 如何选择

- 最丰富的写作体验，自我托管和免费？ **LightCMS**
- 多供应商，战斗测试？ **Decap CMS**
- 在页面上编辑？ **TinaCMS**
- 本地第一开发者文件？ **Keystatic**
- 最轻的设置？ **Sveltia CMS**
- 用预算管理服务？ **CloudCannon**

## 常见问题

### 页面CMS是否免费？

是。在Vercel上托管、自行托管或部署，页面CMS是许可和完全免费的。

### 最接近的页面CMS有什么更丰富的编辑器？

LightCMS：相同的 GitHub 本地、 Markdown 模式，但使用完整的视觉编辑器并捆绑了AI 副本和通讯功能。

### 这些替代方法能够使用我现有的页面CMS内容吗？

是。一切都是 Markdown 在 YAML 前端在您的仓库中。切换编辑器不需要内容迁移。
