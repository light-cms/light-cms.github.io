CMS - это Git основанный на CMS, фокусирующийся на простом формальном редактировании содержимого по всему репозиторию. Команды ищут альтернативы, когда им нужны более богатые интерфейсы, визуальное редактирование, более сильные схемы, поддержка нескольких провайдеров Git или управляемый хостинг.

## Альтернативы на взгляд

| Альтернативный   | Лучший подбор                                                       | Обмен ключами                                                               |
| :--------------- | :------------------------------------------------------------------ | :-------------------------------------------------------------------------- |
| LightCMS         | Редактирование визуального Markdown для статических сайтов          | Проверить текущий набор функций и параметры хостинга                        |
| Разрезать CMS    | Установленный Git основанный на CMS с настраиваемыми коллекциями    | UI/config рабочий процесс может чувствовать себя датированным для писателей |
| TinaCMS          | Визуальное или структурированное редактирование с Git синхронизации | Требует принятия схемы/установочных решений                                 |
| Ключевая статика | Ориентированные на развитие схемы контента первого и первого        | Меньшее внимание на писателя из коробки                                     |
| Sveltia CMS      | Легкий браузерный интерфейс CMS                                     | Младший проект; проверка зрелости                                           |
| Облачная Пушка   | Управляемое визуальное редактирование для команд/агентств           | Коммерческое ценообразование                                                |

## Критерии отбора

При сравнении страниц альтернативы CMS оцениваются:

- Опыт редактирования: поля формы, WYSIWYG или страница редактирования.
- Поддержка провайдера GitHub: только GitLab/Bitbucket.
- Контентная модель: передний материал/формы, типизированные схемы или структурированные блоки.
- Обработка медиа: Загрузки, пути к активам и внешнее хранилище.
- Операционная модель: Размещено SaaS, самостоятельно размещенное приложение или статический интерфейс администрирования.

Для команд, уже использующих Markdown в Git, миграция часто возможна без перемещения контента. Основной работой является отображение полей, путей к мультимедийным путям и редакторский рабочий процесс.
