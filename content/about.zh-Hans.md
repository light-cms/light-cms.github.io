静态场地发电机一旦安装，就很容易被喜欢。为他们撰写可能是一个不同的故事。快速发布不需要打开代码编辑器，修复前面的事项并推送Git提交。

我们生成了 [LightCMS](https://www.lightcms.me/)，这样您就可以在浏览器中写下每个帖子，并且在您自己的 GitHub 仓库中将其保留为 Markdown 文件。这个网站是我们构建LightCMS时的笔记本。我们写了关于什么是有效的，从 Git 发布到哪里会变得很麻烦，以及维护不同的静态站点工具需要什么。
